# Epic 2.12: Корректировки в кассе

**Цель.** Админ может отредактировать ошибочную запись в кассе или удалить её через противоположную (компенсирующую) запись. Полное удаление физически — запрещено (audit trail).

## Контекст

Кассовая запись — это денежное движение. Просто удалять её опасно: пропадёт связь с Payment, нарушится баланс «прошлого» периода. Подход бухгалтерии: правильную запись делаем через **корректирующую** (storno) — то же самое значение с противоположным знаком и пометкой «correction of #N».

## Definition of Done

- В списке последних кассовых операций (`admin/ledger.py`) — клик на запись открывает её карточку
- Кнопки в карточке:
  - «✏️ Изменить описание» (для опечаток — только текст, не суммы)
  - «↩️ Создать корректировку»: открывает FSM «сумма коррекции (положительная или отрицательная) → описание» → создаётся новая LedgerEntry с пометкой «correction of #N» и связью на исходную
- На уровне БД у LedgerEntry появляется поле `corrects_entry_id: int | None` (FK на себя) — для отслеживания цепочки коррекций
- В отчётах (Phase 5) корректировки видны явно
- Любая корректировка пишет в AdminLog с указанием исходной записи
