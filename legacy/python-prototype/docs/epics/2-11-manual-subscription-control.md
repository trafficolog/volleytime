# Epic 2.11: Ручное управление абонементами

**Цель.** Админ может создать абонемент игроку без оплаты (подарок, компенсация), продлить срок действия, изменить количество оставшихся сессий, отменить абонемент с возвратом.

## Контекст

Реальные сценарии:
- «Дать абонемент в подарок за помощь с организацией».
- «Игрок заболел, давайте продлим срок».
- «Случайно списали лишнюю сессию из-за бага — вернуть».
- «Игрок просит возврат за неиспользованный абонемент».

## Definition of Done

- В карточке игрока (Epic 2.8) — кнопка «🎫 Создать абонемент»: выбор плана → подтверждение → новый Subscription в `active` без Payment (или с `Payment.method=cash, status=succeeded, amount=0`)
- В карточке игрока в разделе «Абонементы» — клик на абонемент → его карточка с кнопками:
  - «📅 Продлить срок» (FSM: количество дней)
  - «➕ Добавить сессию», «➖ Убрать сессию» (модификация `total_sessions`, не `used`)
  - «🚫 Отменить» (FSM: причина + опция возврата средств через cash-expense в кассу)
- Все эти операции пишут в AdminLog с подробностями (старое значение → новое)
- При создании подарочного абонемента — уведомление игроку: «вам подарили абонемент 8 тренировок, срок до DD.MM».
