# Epic 4.4: Тесты Phase 4

**Цель.** Тесты на scheduler-задачи. Используем `freezegun` для имитации хода времени, проверяем побочные эффекты (отправлено напоминание, статус Booking изменился).

## Контекст

Тесты планировщика — самые трудные. Нельзя ждать сутки в тесте, чтобы проверить «напоминание за 24 ч». Решение: фрезить время через `freezegun`, вызывать job-функцию напрямую (без планировщика), проверять побочные эффекты.

## Definition of Done

- Тест: за 24 ч до тренировки вызов `send_24h_reminder(training_id)` отправляет сообщение всем confirmed-игрокам (через мок Notifier)
- Тест: повторный вызов в тот же день не приводит к повторной отправке (идемпотентность)
- Тест: при отмене брони между регистрацией задачи и её выполнением — игрок напоминание не получает
- Тест TTL pending_payment: создаём Booking → передвигаем clock на 16 минут → вызываем job → Booking.status == cancelled
- Тест продвижения waitlist: первый из waitlist получил уведомление с TTL → через 30 мин (по clock) переходит к следующему
- `freezegun` в `requirements.txt` (dev-зависимость)
- Все тесты Phase 4 проходят за < 3 сек
