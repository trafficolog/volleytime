# Epic 4.3: Автоматические переходы статусов

**Цель.** Бот сам закрывает «зависшие» бронирования (15 мин), продвигает из waitlist при освобождении места (с TTL 30 мин на подтверждение), переводит прошедшие тренировки в `finished`.

## Контекст

Без этого эпика:
- Игрок открыл бот, нажал «Записаться» → передумал → слот занят, пока админ не отменит вручную.
- Из waitlist никого не двигаем автоматически.
- Прошедшие тренировки висят в `closed`.

Эпик решает три типа гонок:
1. **Pending бронь без оплаты** живёт 15 минут, потом отменяется.
2. **Освобождение слота** → первый из waitlist получает 30 минут на подтверждение → если не подтвердил, следующему.
3. **Прошедшая тренировка** → через 30 минут после окончания становится `finished`, чтобы её можно было закрыть в админ-меню.

## Definition of Done

- При создании Booking в `pending_payment` (Phase 2 cash или Phase 3 unpaid bePaid) — регистрируется задача на отмену через 15 мин
- Если за 15 минут платёж не подтверждён — `Booking.status → cancelled`, слот освобождается, `promote_from_waitlist` вызывается
- При продвижении из waitlist первый игрок получает уведомление с inline-кнопкой «Подтвердить, я приду» (TTL 30 мин)
- Если за 30 мин не подтвердил — снова `cancel + promote_from_waitlist` для следующего
- Прошедшие тренировки через 30 минут после `ends_at` автоматически → `TrainingStatus.finished`
- Все эти задачи — идемпотентны (повторное выполнение ничего не ломает)

## Не делать

- **Не отменяем бронь, оплаченную с абонемента** через TTL — она сразу `confirmed`, TTL не применяется.
- **Не двигаем из waitlist всех сразу.** Только первого, с TTL подтверждения.
- **Не отправляем «вы вышли из waitlist» уведомление** при таймауте — это лишний шум. Просто переходим к следующему.
- **Не переходим автоматически в `cancelled` для тренировки** через какое-либо время. Отменяет только админ.
