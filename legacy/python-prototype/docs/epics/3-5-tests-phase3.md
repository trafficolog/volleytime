# Epic 3.5: Тесты Phase 3

**Цель.** Покрыть тестами всю новую логику Phase 3: проверка подписи, идемпотентность, парсинг webhook, полный цикл оплаты через mock bePaid.

## Контекст

Phase 3 — самая «опасная» фаза с точки зрения багов: ошибка в обработке webhook может привести к двойному списанию, неподтверждённой брони, или (хуже) к чужой брони от подменённого webhook'а. Поэтому тесты обязательны для каждой задачи.

## Definition of Done

- Тесты `verify_bepaid_signature`: правильная подпись → True, неправильная → False, отсутствует ключ → исключение
- Тест идемпотентности: тот же `bepaid_uid` приходит дважды → одна запись в кассе, одно уведомление пользователю
- Тест парсера: разные формы payload (succeeded, failed, refund) разбираются корректно
- Интеграционный тест: полный цикл создание checkout (mock) → симуляция webhook → проверка состояния БД
- Все тесты Phase 3 проходят локально за < 5 секунд
- После Phase 3 общее покрытие тестами по сервисам > 70%
