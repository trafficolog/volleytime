# Epic 2.8: Управление игроками

**Цель.** Полный CRUD-просмотр игроков через админ-меню: список, поиск, карточка с историей бронирований/платежей/абонементов, блокировка/разблокировка, повышение до админа.

## Контекст

После Phase 2 у админа нет способа узнать ничего о конкретном игроке, кроме того, что он видит в текущей карточке тренировки. Если игрок написал в личку «у меня вопрос по моему абонементу» — админу нужно лезть в БД через DBeaver.

## Definition of Done

- В `admin_menu` появилась кнопка «👥 Игроки»
- Список игроков с пагинацией (по 10 на страницу), фильтр «все / активные / заблокированные / админы»
- Поиск по имени / username / Telegram ID
- Карточка игрока: ФИО, контакты, дата регистрации, роль, статус (active/blocked), N бронирований, N посещенных, N no_show, M активных абонементов, T BYN суммарно потратил
- В карточке вкладки: «История записей», «Абонементы», «Платежи», «Кассовые операции с участием»
- Кнопки: «Изменить ФИО», «Изменить телефон», «Заблокировать / Разблокировать», «Сделать админом / Разжаловать» (только root)
- Любое изменение пишется в `AdminLog`
- При блокировке игрока — отмена его активных pending-бронирований (но не confirmed, чтобы не сорвать тренировку другим)
