# Epic 2.9: Управление тренировками

**Цель.** После создания тренировки админ может изменить любое её поле, скопировать как шаблон, или создать серию (например, «Пн и Ср по 19:00 на 4 недели»).

## Контекст

Сейчас тренировка создаётся через FSM один раз. Если ошиблись — можно только отменить и создать заново (но это сорвёт уведомления, восстановления сессий и пр.). Серии вообще не поддерживаются — каждую тренировку нужно создавать руками.

## Definition of Done

- В карточке тренировки (admin/manage.py) появляется кнопка «✏️ Редактировать»
- Изменяемые поля: starts_at, ends_at, venue, price_main, price_rotation, max_main_slots, max_rotation_slots, notes
- Защита: нельзя изменить тренировку, у которой уже есть прошедшее время или статус `finished`/`cancelled`
- При изменении даты/места — уведомление всем confirmed/pending участникам
- При изменении цены — текст: «цена изменена с X на Y, уже совершённые оплаты не пересчитываются»
- Кнопка «📋 Копировать» в карточке: создаёт новую тренировку с теми же параметрами, дата выбирается в FSM
- Кнопка «🔁 Создать серию» в admin_menu: FSM из шагов «дни недели → время → начало → конец → venue → цена» → создаёт N тренировок одним действием
- Все правки и копии пишутся в `AdminLog`
