# Phase 1: MVP-каркас

**Цель.** Работающая структура проекта, по которой можно итеративно наращивать функциональность. Бот отвечает на `/start`, регистрирует пользователей, позволяет создавать тренировки и записываться на них без интеграции оплат.

## Контекст

Это первая фаза — фундамент. Здесь решаются ключевые архитектурные вопросы (async-стек, SQLAlchemy 2.0, схема БД), которые задают форму остальным фазам.

## Definition of Done

- Бот стартует по `python -m src.bot.main`
- `/start` приветствует, создаёт пользователя в БД
- Админ может создать тренировку через FSM
- Игрок видит ближайшие тренировки в списке
- Запись попадает в правильный слот (main → rotation → waitlist)
- Отмена записи освобождает место
- Все юнит-тесты проходят
