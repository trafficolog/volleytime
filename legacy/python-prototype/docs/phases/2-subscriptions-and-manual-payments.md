# Phase 2: Абонементы + ручная оплата

**Цель.** Полноценный рабочий бот, в котором можно записываться, покупать абонементы и фиксировать оплату наличными или переводом — без интеграции с платёжной системой.

## Зачем эта фаза

Позволяет запустить бот в реальной группе уже сейчас, пока оформляется ИП/самозанятость для bePaid (это может занять 2–4 недели). Параллельно — обкатываются UX-решения и собираются метрики.

## Контекст

После Фазы 1 у нас есть базовый каркас. Теперь добавляем:
- покупку и списание абонементов,
- выбор способа оплаты при записи,
- кассу с доходами/расходами,
- меню «Мои» для игрока,
- расширенную админ-панель.

## Definition of Done

- Бот можно запустить в реальной группе без bePaid
- Игроки записываются с выбором: абонемент / наличные
- Админ подтверждает оплаты кнопкой
- В кассе видно: пришло, потратили, остаток
- Тесты SubscriptionService, LedgerService, PaymentService покрывают основные сценарии
