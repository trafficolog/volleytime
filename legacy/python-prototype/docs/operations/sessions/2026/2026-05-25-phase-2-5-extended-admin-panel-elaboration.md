# Сессия 2026-05-25: создание Phase 2.5 «Расширенная админ-панель»

## Цели

Оператор обнаружил, что текущий набор задач Phase 3-6 не покрывает критически важные админ-возможности, нужные с первого дня работы в реальной группе:

- Список и управление игроками (карточки, история, блокировка, роли)
- Редактирование уже созданных тренировок (даты, цены, лимиты)
- Серии повторяющихся тренировок
- Ручная запись/снятие/перенос участников
- Создание подарочных абонементов и ручное управление
- Корректировки в кассе (а не только новые записи)
- Управление планами абонементов через UI (без деплоя для изменения цен)
- Базовые настройки бота через UI

## Контекст

После Phase 2 wrap-up бот функционально работоспособен для запуска в группе с ручной оплатой. Но всё управление, кроме создания тренировки и подтверждения платежа — недоступно без прямого SQL.

В реальной жизни постоянно возникают мелкие операции: «Петя написал в личку — запиши его», «давайте поднимем цены», «исправьте описание в кассе». Без этих возможностей бот превращается в препятствие, а не помощника.

## Ход работы

### Шаг 1. Анализ пробелов

По каждой области (пользователи, тренировки, записи, абонементы, касса, планы, настройки) — что сейчас есть, чего не хватает. Результат:

| Область | Есть | Не хватает |
|---------|------|------------|
| Пользователи | в карточке тренировки видно имена | список, поиск, карточка, блокировка, роли |
| Тренировки | создание, отмена, отметка посещаемости | редактирование, копирование, серии |
| Записи | пользователь сам делает | админ за пользователя, снятие, перенос |
| Абонементы | покупка через flow | подарок, продление, корректировка сессий |
| Касса | добавление | редактирование, корректировки |
| Планы абонементов | hardcoded в коде | CRUD через UI |
| Настройки | в config.py | через UI без деплоя |

### Шаг 2. Дизайн Phase 2.5

**Решение по нумерации:** новая «фаза» = 2.5, чтобы не ломать существующие номера Phase 3-6. Эпики продолжают сквозную нумерацию эпиков Phase 2: 2.8 — 2.14. Это сохраняет линейную ID-схему и не требует переименования файлов.

**Структура:**
- 7 эпиков по логическим областям
- 22 задачи внутри (от 2 до 4 на эпик)
- Оценка трудозатрат: 40-60 ч
