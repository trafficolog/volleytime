## Найденные баги по пути

1. **SQLite не хранит таймзону.** При `session.get()` возвращался naive datetime, что ломало сравнение `expires_at <= now_msk()`. Исправлено: везде используется `to_msk(dt)` для приведения к aware.
2. **Порядок проверок в `consume_session`.** После списания последней сессии статус становился `depleted`, и следующий вызов бросал `NoActiveSubscriptionError` вместо ожидаемого `SubscriptionDepletedError`. Переставил проверки: сначала по количеству сессий, потом по статусу.
