✅ **Phase 2 завершена.** Все 21 задачи выполнены, 25 тестов проходят, бот готов к запуску в реальной группе с ручной оплатой.

### Следующий шаг — Phase 2.5 «Расширенная админ-панель»

⚪ **Phase 2.5** — 22 новые задачи, ~40-60 часов. Закрывает то, что нужно с первого дня работы в реальной группе:

- 👥 [2.8](phases/2-5-extended-admin-panel.md) Управление игроками (список, карточки, история, блокировка, роли)
- 📅 [2.9](phases/2-5-extended-admin-panel.md) Управление тренировками (редактирование, копирование, серии)
- 📋 [2.10](phases/2-5-extended-admin-panel.md) Ручное управление записями (запись за игрока, перенос)
- 🎫 [2.11](phases/2-5-extended-admin-panel.md) Ручное управление абонементами (подарки, продление, возврат)
- 💰 [2.12](phases/2-5-extended-admin-panel.md) Корректировки в кассе (правка, сторно)
- ⚙️ [2.13](phases/2-5-extended-admin-panel.md) CRUD планов абонементов (изменение цен без деплоя)
- 🔧 [2.14](phases/2-5-extended-admin-panel.md) Настройки через UI (цены, лимиты, тайминги)

### Параллельно — Трек A (Юридическое)

- ⏸ Отправить обращение в МНС РБ по [шаблону](./TAXES_BY.md#шаблон-письменного-обращения-в-мнс)

### После Phase 2.5

После регистрации ИП/НПД:

- ⚪ Phase 3 — интеграция bePaid (15 задач)

- ⚪ Phase 6 — деплой 24/7 (12 задач)

## Зависимости между фазами

```
Фаза 1 ────────► Фаза 2 ────────► Фаза 2.5 (Admin Panel) ────► Фаза 3 (bePaid)
                                       │                            ▲
                                       │                            │
                                       │                            │ зависит от
                                       ▼                            │
                                   Трек A: МНС + регистрация ИП/самозанятости
                                       │
                                       └── 2-3 недели ожидания

Фаза 1 ──┬──► Фаза 4 (Scheduler) — можно делать параллельно с Фазой 2 / 2.5 / 3
         │
         └──► Фаза 5 (отчёты, экспорт) — после Фазы 4 для полноты

Фаза 3 + Фаза 4 + Фаза 5 ────► Фаза 6 (Production deploy)
```

**Критический путь к проду:** Фаза 1 → Фаза 2 → Фаза 2.5 → Трек A (МНС) → Фаза 3 → Фаза 6.

Оптимистичная оценка: 8–10 недель (с учётом 2–3 недель ожидания МНС и 40-60 часов Phase 2.5).

## Метрики успеха

После Фазы 2 (запуск с ручной оплатой):
- 80%+ записей через бот, а не через сообщения в группу
- Время записи на тренировку < 30 секунд

После Фазы 3 (bePaid):
- 95%+ оплат проходят автоматически
- 0 случаев двойного списания

После Фазы 6 (прод):
- Uptime > 99% / месяц
- Время восстановления после сбоя < 30 минут
