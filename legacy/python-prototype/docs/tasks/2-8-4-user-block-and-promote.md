# Task 2.8.4: Блокировка и управление ролью

## Цель

Из карточки игрока (Task 2.8.2) админ может заблокировать/разблокировать игрока и (только root-админ) повысить до admin / разжаловать.

## Контекст

**Блокировка** — это не удаление. Заблокированный игрок видит сообщение «Вы заблокированы, обратитесь к организатору» при любых действиях. Существующие confirmed-брони не сорваны (тренировки идут как обычно), но новых записей он сделать не может.

**Управление ролью** — двухуровневое. Root-админ (тот, кто в `ADMIN_TELEGRAM_IDS` в `.env`) — нельзя разжаловать через бот. Promoted-админ (`User.role = admin`) — root может снимать.

## Что должно быть сделано

- Кнопка «🚫 Заблокировать» / «✅ Разблокировать» в карточке игрока, зависит от текущего статуса `is_active`
- При блокировке:
  - Двухшаговое подтверждение через inline-клавиатуру
  - Поле «причина» (свободный FSM-шаг)
  - `User.is_active = False`
  - Все его pending-брони → cancelled (с promote_from_waitlist)
  - Запись в AdminLog (action="user_blocked", details={reason})
  - Уведомление игроку: «Вы заблокированы. Причина: ... Обратитесь к организатору @admin_username»
- При разблокировке: аналогично, без причины
- Кнопка «👑 Сделать админом» / «👤 Разжаловать»:
  - Видна **только** если текущий админ — root
  - Root-проверка: `current_user.telegram_id in settings.admin_telegram_ids`
  - Нельзя разжаловать root-админа (его роль определена в `.env`)
  - `User.role = admin / player`
  - Запись в AdminLog (action="role_changed", details={old, new})
  - Уведомление игроку при назначении: «Вы назначены администратором. Используйте /start для нового меню.»
- Middleware uses_role должен учитывать `is_active`: заблокированный пользователь не получает админ-функций, даже если `role=admin`

## Критерии приёмки

- Promoted-админ не видит кнопки «Сделать админом» / «Разжаловать»
- Root-админ видит, но не может разжаловать root
- При блокировке: pending-брони отменены, confirmed — нет
- При попытке заблокированного использовать бот — сообщение про блокировку
- Все операции в AdminLog
- Уведомления приходят целевому игроку (если не заблокировал бот)

## Подсказки

- Проверка root: `user.telegram_id in settings.admin_telegram_ids` (settings.admin_telegram_ids — это list[int])
- Middleware: в `UserMiddleware` (или новый `RoleMiddleware`) при проверке `is_admin()` — учитывать `user.is_active`
- Если заблокировать самого себя — это самопотопление. Не давать (`user_id != current_user.id`)
- При попытке заблокировать root — отказать с пометкой «нельзя блокировать root-админа»

## Не делать

- Не давать promoted-админу управлять ролями. Только root.
- Не отменять confirmed-брони при блокировке — это сорвёт реальную тренировку другим.
- Не возвращать оплаты автоматически при блокировке — это делает админ вручную через Epic 2.11 (refund subscription).
