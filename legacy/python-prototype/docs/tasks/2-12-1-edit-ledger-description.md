# Task 2.12.1: Редактирование описания записи в кассе

## Цель

В списке кассовых операций (admin/ledger.py) клик на запись открывает её карточку. Кнопка «✏️ Изменить описание» — позволяет только текст, не сумму, не категорию, не дату.

## Контекст

Опечатки случаются: «арнеда» вместо «аренда», или «зал 5 мая» вместо «зал 8 мая». Эту мелочь нужно уметь править без танцев с корректировками. А вот сумму и тип — только через 2.12.2.

## Что должно быть сделано

- В существующем `admin/ledger.py` доработать `cb_list_recent`: каждая запись становится отдельной inline-кнопкой с callback `admin:ledger:view:<entry_id>`
- Хендлер `admin:ledger:view:<entry_id>`:
  - Загрузить LedgerEntry
  - Показать карточку:
    ```
    💰 Запись #N
    Тип: income · Категория: training_fee
    Сумма: 15.00 BYN
    Дата: 25.05.2026
    Описание: оплата за тренировку (Пётр Петров)
    Связь: Payment #42

    ✏️ Изменить описание
    ↩️ Создать корректировку
    « К кассе
    ```
- Кнопка «✏️ Изменить описание» → FSM `EditLedgerDescription.waiting_value`
- При получении нового текста:
  - Валидация: длина 1-500 символов
  - Сохранение в `LedgerEntry.description`
  - AdminLog (action="ledger_description_edited", details={old, new})

## Критерии приёмки

- Описание можно изменить
- Сумму через эту кнопку изменить нельзя (нет такой кнопки)
- Изменение в AdminLog
- Карточка обновляется

## Подсказки

- Это самая простая задача в Phase 2.5 — буквально одно поле.
- Не давать редактировать связи (`related_payment_id`, `related_training_id`) — они системные.

## Не делать

- Не менять суммы (только через 2.12.2).
- Не давать удалять описание полностью (минимум 1 символ — точка).
