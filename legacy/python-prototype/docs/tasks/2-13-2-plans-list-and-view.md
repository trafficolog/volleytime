# Task 2.13.2: Список планов и просмотр

## Цель

В admin_menu — кнопка «🎫 Планы абонементов». Список всех планов (активных и деактивированных), клик на план — карточка с подробностями и кнопками управления.

## Контекст

Точка входа для всех операций над планами (создание в 2.13.3, редактирование цены, деактивация).

## Что должно быть сделано

- В `admin_menu` кнопка «🎫 Планы абонементов» → `admin:plans:list`
- Хендлер `admin:plans:list`:
  - Запрос всех планов (включая is_active=false)
  - Сортировка по `sort_order ASC, created_at ASC`
  - Список:
    ```
    🎫 Планы абонементов

    ✅ 4x — 4 сессии, 56 BYN, 35 дней (использует 8 человек)
    ✅ 8x — 8 сессий, 104 BYN, 60 дней (использует 12 человек)
    ✅ 12x — 12 сессий, 144 BYN, 90 дней (использует 3 человека)
    ⚪ promo (неактивен) — 3 сессии, 42 BYN, 14 дней (исп. 0)

    [➕ Создать план] [« Назад]
    ```
  - Каждый план — отдельная inline-кнопка → `admin:plan:view:<plan_id>`
- Хендлер `admin:plan:view:<plan_id>` — карточка плана:
  ```
  🎫 План 8x — Месячный
  
  Код: 8x
  Сессий: 8
  Цена: 104.00 BYN (за тренировку: 13.00 BYN)
  Срок действия: 60 дней с момента покупки
  Статус: ✅ Активен
  Sort order: 2
  
  📊 Статистика
  Куплено всего: 47 раз
  Активных сейчас: 12
  
  ✏️ Цена · ✏️ Сессий · ✏️ Срок · ✏️ Название
  🔁 Активировать / 🚫 Деактивировать
  « К списку
  ```
- Подсчёт «использует N человек» = `SELECT COUNT(*) FROM subscriptions WHERE plan_code = X AND status = 'active'`
- Если у плана есть активные подписки — кнопки редактирования цены/сессий показывают предупреждение «изменение не повлияет на уже купленные абонементы»

## Критерии приёмки

- Список показывает все планы (активные и неактивные)
- Статистика «активных X» корректна
- Карточка плана показывает все поля
- Сортировка работает

## Подсказки

- Sort_order даёт админу управлять порядком в UX-меню покупки.

## Не делать

- Не показывать в публичном меню покупки (для игроков) неактивные планы (Phase 2.13.3 решает это автоматически через `is_active=true` фильтр).
- Не пересчитывать статистику в реальном времени для дашборда — только при открытии экрана.
