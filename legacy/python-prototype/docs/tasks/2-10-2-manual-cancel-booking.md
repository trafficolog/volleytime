# Task 2.10.2: Снятие чужой записи с причиной

## Цель

В карточке тренировки клик по игроку открывает миникарточку Booking с кнопкой «🚫 Снять запись». Перед снятием — FSM с обязательной причиной. После снятия — восстановление сессии абонемента / refund-логика как при отмене самим пользователем + уведомление.

## Контекст

Сценарии: «игрок не выходит на связь, нужно освободить место», «игрок попросил снять, но через 24 ч (когда сам уже не может)».

## Что должно быть сделано

- Доработать `cb_training_view` в `admin/manage.py`: имена в составе делать кликабельными → callback_data `admin:booking:view:<booking_id>`
- Хендлер `admin:booking:view:<booking_id>` — миникарточка:
  ```
  📋 Запись #42
  Игрок: Пётр Петров @petrov
  Тренировка: DD.MM.YYYY HH:MM
  Слот: main · Статус: confirmed
  Оплата: 15 BYN наличными · succeeded

  [🚫 Снять запись] [« К тренировке]
  ```
- Кнопка «🚫 Снять запись» → FSM `CancelBookingByAdmin.waiting_reason`:
  - Бот: «Причина отмены?» (свободный текст)
- При получении причины:
  - Booking.status → cancelled, cancellation_reason = "by_admin: " + reason
  - Если был subscription_id → restore_session (как при обычной отмене)
  - Если был оплачен наличными и тренировка через ≥ 24 ч → опция возврата средств (отдельная inline-клавиатура «Вернуть наличными? [Да + expense в кассу] [Нет]»)
  - promote_from_waitlist
  - Уведомление игроку: «Ваша запись на TRAINING снята администратором. Причина: ...»
  - AdminLog (action="admin_cancel_booking", details={booking_id, reason, refund})

## Критерии приёмки

- Кликабельность имени в составе работает
- Причина обязательна (FSM не пропускает пустое)
- При снятии subscription-брони сессия возвращается
- При снятии cash-брони админ может выбрать возврат
- Игрок получает уведомление
- AdminLog заполнен

## Подсказки

- Переиспользовать существующий `BookingService.cancel_booking` (если есть подходящая сигнатура).
- Уведомление: формат полей из `format_dt_human()`.

## Не делать

- Не создавать «черновики» отмен — сразу финал.
- Не отменять прошедшие тренировки — для них есть посещаемость.
- Не давать массово снимать игроков (это Phase 5 если понадобится).
