# Task 2.6.4: Отмена тренировки с возвратом

## Цель

Дать админу отменить тренировку с массовым уведомлением и возвратом денег/сессий.

## Контекст

Иногда тренировка отменяется по объективным причинам (нет зала, болезнь админа). Все участники должны быть уведомлены, оплаты возвращены, сессии абонементов восстановлены.

## Что должно быть сделано

- Кнопка «Отменить тренировку» в карточке тренировки
- Подтверждение через FSM (нельзя отменить случайно)
- Для каждой записи: cancel, restore session ИЛИ создать refund-Payment (для cash)
- В Фазе 3 — refund через bePaid API
- Массовая рассылка уведомлений
- Запись expense в кассу для refund (для cash)

## Критерии приёмки

- Training.status → cancelled
- Все Booking → cancelled
- Все subscription-сессии восстановлены
- Все cash-платежи помечены как требующие возврата
- Игроки получили уведомление
