# Task 2.9.3: Создание серии повторяющихся тренировок

## Цель

В admin_menu — кнопка «🔁 Создать серию». FSM генерирует сразу N тренировок по правилу: «Каждый Пн и Ср в 19:00 с 1 июня по 30 июня».

## Контекст

Самый востребованный сценарий стартового запуска: «У нас группа стабильно играет Пн и Ср». Создать 8 тренировок руками — час времени. Серия — 1 минута.

## Что должно быть сделано

- Кнопка «🔁 Создать серию» в `admin_menu`
- FSM `CreateSeries`:
  1. `waiting_weekdays` — inline-клавиатура с днями недели, toggle, кнопка «Готово»
  2. `waiting_time` — «Во сколько начало? Формат HH:MM»
  3. `waiting_duration_hours` — «Длительность в часах»
  4. `waiting_start_date` — «С какой даты начинать? DD.MM.YYYY (по умолчанию — сегодня)»
  5. `waiting_end_date` — «По какую дату? DD.MM.YYYY»
  6. `waiting_venue` — «Место»
  7. `waiting_price` — «Цена за тренировку»
  8. Подтверждение: «Создать 8 тренировок? [✅ Да] [❌ Отмена]»
- При подтверждении:
  - Генерация списка дат: для каждого дня от start_date до end_date — если weekday() в выбранных, добавить тренировку с заданным временем
  - Создание Training в цикле (по одной транзакции на все, или порциями по 10)
  - Запись в AdminLog: action="series_created", details={count, weekdays, range}
  - Сообщение: «✅ Создано N тренировок. [Перейти к списку]»
- Защита: если в выбранном диапазоне уже есть тренировки в эти же даты+время — предупреждение «Найдено M пересечений. Пропустить дубли? [✅ Да, пропустить] [⚠️ Создать всё равно]»

## Критерии приёмки

- Серия «Пн+Ср с 01.06.2026 по 30.06.2026 в 19:00» создаёт 9 тренировок (4 понедельника + 5 сред = 9, проверить точно)
- Все тренировки имеют одинаковые параметры
- При пересечении с существующими — корректное предупреждение
- При отмене на любом шаге — нет частичных тренировок
- В AdminLog одна запись с агрегатом, не N

## Подсказки

- Дни недели: Pn=0, Vt=1, ..., Vs=6. В Python `date.weekday()` возвращает 0-6.
- Iterate: `current = start_date; while current <= end_date: if current.weekday() in weekdays: ...; current += timedelta(days=1)`
- Транзакция: либо all-or-nothing через один `await session.commit()` в конце, либо по 10 с `await session.flush()`.

## Не делать

- Не учитывать выходные/праздники автоматически. Админ сам исключит вручную если что.
- Не отправлять уведомления игрокам при создании серии — это пустые тренировки без записей.
