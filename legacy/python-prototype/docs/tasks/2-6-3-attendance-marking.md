# Task 2.6.3: Отметка посещаемости

## Цель

Дать админу возможность отметить, кто пришёл на тренировку (attended) и кто не пришёл (no_show).

## Контекст

После окончания тренировки админ открывает её карточку и видит список с чекбоксами. Эти данные нужны для статистики (Фаза 5) и для возможной политики «3 no_show подряд — предупреждение».

## Что должно быть сделано

- Кнопка «Отметить посещаемость» в карточке прошедшей тренировки
- Inline-клавиатура с именем игрока и переключателем attended/no_show
- Массовое сохранение
- Auto-finished статус для тренировки после отметки

## Критерии приёмки

- Кнопка появляется только для тренировок со статусом `closed` или `finished`
- Изменение Booking.status: confirmed → attended | no_show
- Нельзя отметить отменённую бронь

## Не делать

- Не отправлять уведомления игрокам про их no_show в этой задаче
- Не делать автоматическую блокировку (это в Фазе 5)
