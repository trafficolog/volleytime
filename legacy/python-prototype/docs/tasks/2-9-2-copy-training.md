# Task 2.9.2: Копирование тренировки как шаблон

## Цель

В карточке тренировки кнопка «📋 Копировать». Создаёт новую тренировку с теми же параметрами (venue, prices, slot_limits, notes), запрашивая только новую дату.

## Контекст

Самый частый сценарий: «На следующей неделе всё то же самое, но в другую дату». Сейчас — создавать с нуля.

## Что должно быть сделано

- Кнопка «📋 Копировать» в `cb_training_view`
- Хендлер `admin:training:copy:<id>`:
  - Сохранить source_training_id в FSM-state
  - Запросить новую дату: «Скопировать на какую дату? Формат DD.MM.YYYY HH:MM»
- Получение даты → создание нового Training:
  - venue, price_main, price_rotation, max_main_slots, max_rotation_slots, notes — из source
  - starts_at — из ввода
  - ends_at = starts_at + (source.ends_at - source.starts_at)
  - status = `open` (или `planned` — выбрать)
- Регистрация scheduler-задач (после Phase 4)
- AdminLog: action="training_copied", details={source_id, new_id}
- Сообщение админу: «✅ Создана новая тренировка #N на DD.MM.YYYY HH:MM. [Перейти к карточке]»

## Критерии приёмки

- Копия имеет все те же параметры, кроме даты
- Старая тренировка не изменилась
- Новая видна в списке предстоящих
- В AdminLog связь source → new

## Подсказки

- Не копировать `notes` если они содержат специфику конкретной даты (типа «у Пети ДР»). Можно дать опцию «Копировать без заметок».
- Альтернатива: сразу копировать в «следующую такую же дату» (через 7 дней) — но это `2.9.3` (серии).

## Не делать

- Не копировать брони (это новая тренировка, состав свежий).
- Не делать «расписание шаблонов» с named-шаблонами — лишняя сложность.
