# Task 3.1.3: Поддержка ЕРИП

## Цель

В существующем `BePaidClient.create_checkout` добавить возможность создавать checkout с `payment_method_types=["erip"]` для платежей через ЕРИП. На стороне UX (Epic 3.3) — отдельная кнопка «Оплатить через ЕРИП».

## Контекст

ЕРИП — единая расчётная система Беларуси. Клиент оплачивает через свой банковский клиент (Беларусбанк, Приорбанк, БПС-Сбербанк и пр.), не вводя данные карты.

С точки зрения bePaid это просто другой `payment_method_type`. Hosted page и webhook работают так же.

Отличие в UX: для ЕРИП пользователю показывают **код услуги** и пошаговую инструкцию: «Откройте банковский клиент → Платежи → ЕРИП → Найти услугу [код] → Оплатить».

## Что должно быть сделано

- Параметр `payment_method_types` в `create_checkout` уже есть (из 3.1.1). Проверить, что он корректно прокидывается в payload как `"settings.payment_method.types": ["erip"]`.
- Если в `settings.bepaid_erip_enabled = True` — UI Epic 3.3 показывает отдельную кнопку «ЕРИП»; иначе — нет.
- В payload checkout для ЕРИП добавить дополнительные поля, требуемые bePaid:
  - `customer.first_name`, `customer.last_name` (берём из `User.full_name` — split по пробелу)
  - дополнительные поля по требованию bePaid (см. их доку)
- Тест: payload содержит `"types": ["erip"]` при ЕРИП-режиме

## Критерии приёмки

- Тест: создание checkout с `payment_method_types=["erip"]` формирует корректный payload
- Документация в `docs/BEPAID.md` обновлена: какие поля обязательны для ЕРИП
- В UI Phase 3 кнопка «ЕРИП» появляется и работает (см. 3.3.1)

## Подсказки

- bePaid позволяет смешать методы: `["credit_card", "erip"]` — пользователь сам выберет на hosted page.
- Альтернатива «отдельная кнопка ЕРИП» vs «выбор на hosted page»: лучше отдельная кнопка, т.к. пользователю чётко понятно, какой способ.
- `customer.first_name`/`last_name` могут быть обязательными для ЕРИП — проверить в их доке.

## Не делать

- Не делаем интеграцию ЕРИП напрямую через НБРБ — только через bePaid.
- Не показываем код услуги ЕРИП в боте — hosted page показывает сам.
- Не парсим QR-код ЕРИП в боте — это в задаче 3.3.3 (опционально).
