# Epic 6.6: UI касса (баланс, история, расходы)

**Цель.** Mini App страница кассы: текущий баланс, история операций (income/expense), форма добавления расхода.

## Контекст

Организатор видит финансовое состояние группы: сколько собрано, потрачено, баланс. Вводит расходы (аренда зала, мячи). Переиспользует useFormatters, labels.

## Definition of Done

- `/m/orgs/:orgId/cashbox` — баланс (крупно), история операций
- История: income (зелёный +) / expense (красный −), категория, описание, дата
- Кнопка «Добавить расход» → sheet (категория, сумма, описание)
- Фильтр по типу/категории (опционально)
- Суммы и категории на русском
- Только owner/organizer
