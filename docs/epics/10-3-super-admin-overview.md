# Epic 10.3: Super-admin обзор беты

**Цель.** Служебный обзор (вне обычных ролей) для соло-разработчика, ведущего бету: список бета-организаций с метриками активности (события, брони, последняя активность, баланс кассы).

## Контекст

Решение 5: лёгкий super-admin обзор. Помогает вести бету — видеть кто активен, кто застрял, собирать гейт-метрики. НЕ полноценная админка (это позже), минимальный read-only обзор + управление allowlist.

## Definition of Done

- Super-admin доступ (по telegram_id из env/allowlist, отдельно от org-ролей)
- Обзор бета-организаций: название, организатор, дата создания, метрики
- Метрики активности: кол-во событий, броней, последняя активность, активные участники
- Гейт-метрики на виду (помогает оценивать готовность к Phase 7)
- Управление allowlist (10.1) из этого обзора
- Read-only по данным организаций (не вмешиваемся, только наблюдаем)
