# Epic 3.8: GitHub Actions CI

**Цель.** Настроить GitHub Actions workflow, который на каждый push/PR проверяет: typecheck, lint, unit-test, integration-test. **Docker build не делаем** (это Phase 9).

## Контекст

CI должен быть **быстрым** (≤ 3 минуты) и **надёжным**. На MVP размер кода маленький, тесты быстрые. Pull request с красным CI — не мержим.

## Definition of Done

- Создан `.github/workflows/ci.yml`
- Триггеры: push в `main`, pull request в `main`
- Jobs:
  - `lint` — `pnpm lint` + `pnpm format:check`
  - `typecheck` — `pnpm typecheck`
  - `test` — `pnpm test` (unit)
  - `test:integration` — `pnpm test:integration` с PG service container
- Turborepo cache между runs (через actions/cache)
- Все jobs запускаются параллельно (кроме integration, который требует PG service)
- Badge в README со статусом CI
- На push в `main`: те же checks + проверка, что миграции применяются на чистой БД
