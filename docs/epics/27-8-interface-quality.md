# Epic 27.8: Качество интерфейса

**Цель.** Интерфейс проще поддерживать и проверять: крупные компоненты разделены, общая логика кабинета и Mini App не дублируется, доступность и устройства проверяются системно.

## Контекст

Фаза [27](../phases/27-audit-hardening.md). Источник — [аудит 2026-11-10](../operations/reviews/2026-11-10-project-audit.md), раздел 4 (UI) и PROD-17.

PROD-17 (iOS и Telegram Web вне матрицы) совпадает с UI-04 и отдельной карточки не получает. Карточки рефакторинга идут после v0.3.1, чтобы не конфликтовать с 21.4.x по файлам.

## Definition of Done

- Крупнейшие компоненты разделены без изменения поведения.
- Общая логика форм события, оплат и кассы вынесена из страниц.
- Автоматическая проверка доступности в CI; матрица устройств в каждом релизе.
