# Epic 7.4: Тарифная сетка (настраиваемая) + расчёт цены

**Цель.** Настраиваемая тарифная сетка: пороги количества → цена за кредит (root-admin редактирует). Расчёт суммы для произвольного количества (flat-tier). Подсказки-пакеты.

## Контекст

Решение 4 (вариант C): root-admin задаёт сетку (с какого количества другая цена), покупатель вводит любое количество (тест тоже), сумма авто-считается. Гибко для экспериментов с ценой.

Flat-tier: для Q берётся tier с наибольшим min_quantity ≤ Q, все Q по этой цене.

## Definition of Done

- credit_pricing_tiers (min_quantity, price_per_credit), редактируемая
- Дефолтная сетка (seed): 1→500, 10→400, 30→350, 100→300 (BYN minor)
- calculatePrice(quantity): находит tier, возвращает total + price_per_credit
- Произвольное количество (≥1), цена по сетке
- Подсказки-пакеты (suggested quantities) — из порогов или конфиг
- Валидация сетки (пороги возрастают, цены положительные)
- Root-admin CRUD тарифов (эпик 7.7)
