# Epic 28.1: Граф знаний репозитория (Graphify)

**Цель.** Агенты и люди отвечают на вопросы «где это», «что с чем связано», «что затронет изменение» запросом к локальному графу знаний вместо полного чтения файлов; ни секреты, ни служебные данные выкладки не попадают в граф и тем более наружу.

## Контекст

Фаза [28](../phases/28-developer-tooling.md). Запрос владельца 2026-11-20.

Сведения о Graphify на 2026-11-20 (README и релизы репозитория `Graphify-Labs/graphify`, прочитаны через `gh`, ничего не устанавливалось):

- Лицензия Apache-2.0. Последний релиз `v0.9.113` от 2026-11-19; релизы выходят раз в 2–3 дня. В репозитории есть workflow `publish.yml` и `release-graph.yml`.
- Пакет PyPI — `graphifyy` (две `y`); README прямо предупреждает, что другие пакеты `graphify*` не связаны с проектом. Команда CLI — `graphify`.
- Требования: Python 3.11+, `uv` (рекомендуется) или `pipx`. Windows поддерживается (`winget install astral-sh.uv`, `graphify install` определяет платформу). Node-зависимостей и lock-файлов в репозитории проекта не появляется.
- Код разбирается локально tree-sitter AST, без LLM, «ничего не покидает машину». Документы, PDF, изображения и видео — семантический проход через модель ассистента или настроенный backend (`--backend claude` с `ANTHROPIC_API_KEY`, OpenAI, Gemini, Azure, Bedrock, Ollama локально). Телеметрии нет по заявлению README.
- Игнор: учитывается `.gitignore`, плюс `.graphifyignore` и `--exclude`; `--no-gitignore` отключает только VCS-правила. Проектные настройки — `.graphifyrc` (`key=value`).
- Выход — `graphify-out/` (`graph.html`, `GRAPH_REPORT.md`, `graph.json`). Обновление: `--update` (только изменённые файлы), `graphify update .`, `graphify watch` (extra `watch`), `graphify hook install` (git-хуки на commit и checkout).
- `graphify install --project` пишет настройки под текущий каталог вместо профиля пользователя. Для Claude Code ставится хук, который срабатывает перед Read/Glob/`cat`/`grep` и подталкивает агента к графу.
- Есть extras `sql` (схема SQL) и `postgres` (живая интроспекция по DSN), `graphify prs --triage` (отправляет данные PR настроенному backend), Graphify Cloud (облачный сервис, не используется).

## Definition of Done

- Версия, способ установки и происхождение пакета проверены и записаны; установка воспроизводима одной командой.
- Правила игнора исключают секреты, служебные данные выкладки и шум; проверка показывает, что их нет в `graph.json`.
- Граф кода построен локально, базовая оценка полезности записана.
- Семантический проход по документам выполнен только по папкам, разрешённым владельцем, и только выбранным владельцем backend.
- Правила для агентов: когда спрашивать граф, как обновлять, что не делать.
