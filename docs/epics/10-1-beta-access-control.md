# Epic 10.1: Beta access control (allowlist)

**Цель.** Ограничить создание новых организаций приглашёнными (allowlist). Игроки заходят свободно по org-invite (Phase 4), но новые организации создают только из allowlist.

## Контекст

Решение 3: контролируемый рост. Закрытая бета = не все подряд создают организации. Allowlist по telegram_id организатора или invite-коду. Снимается легко (флаг) при выходе из беты.

## Definition of Done

- Allowlist-механизм: создание организации разрешено только allowlisted пользователям
- Управление allowlist (добавить/убрать организатора) — через super-admin (10.3) или конфиг
- Игроки НЕ ограничены (присоединение по org-invite работает как в Phase 4)
- Понятное сообщение не-allowlisted при попытке создать организацию
- Флаг беты: легко отключить allowlist при открытии (env/config)
