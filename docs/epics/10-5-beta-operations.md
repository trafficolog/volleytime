# Epic 10.5: Beta operations (onboarding/support/feedback runbooks)

**Цель.** Формализовать ведение беты в исполнимые артефакты: onboarding-чеклист (подключение организатора), support-runbook (реакция на проблемы), feedback-трекинг (фиксация/приоритизация).

## Контекст

Решение 6: формализация в runbooks. Чтобы вести бету системно (не по памяти). На основе PRIVATE_BETA_PLAN.md + опыта Трека B. Это операционные документы, не код.

## Definition of Done

- Onboarding-чеклист: пошаговый процесс подключения нового бета-организатора (от first contact до первого события)
- Support-runbook: типовые проблемы, реакция, эскалация, SLA для беты
- Feedback-трекинг: как фиксировать обратную связь, приоритизировать (severity), связывать с задачами
- Все в docs/operations/runbooks/
- Повторяемость (любой может подключить организатора по чеклисту)
