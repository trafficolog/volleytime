# Epic 27.1: Периметр и изоляция сервисов

**Цель.** Снаружи доступно только то, что нужно пользователям; каждый сервис работает с минимальными правами и видит только свои секреты.

## Контекст

Фаза [27](../phases/27-audit-hardening.md). Источник — [аудит 2026-11-10](../operations/reviews/2026-11-10-project-audit.md), раздел 2.1 (INF).

## Definition of Done

- Внутренний API недоступен из интернета; служебные секреты разделены по направлениям.
- Контейнеры web и bot работают не от root, с урезанными capabilities, каждый со своим набором переменных.
- Приложение и мигратор используют разные роли БД.
- Заголовки безопасности и ограничения размера запросов заданы явно и проверяются тестом или smoke.
