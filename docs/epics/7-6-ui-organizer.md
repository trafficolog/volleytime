# Epic 7.6: UI organizer — баланс, история, покупка

**Цель.** Mini App: баланс credits, история транзакций, покупка (ввод количества → авто-сумма по сетке → заявка). Блок создания Event при 0 ведёт сюда.

## Контекст

Решение 9: прозрачность для доверия к монетизации. Организатор видит сколько credits, куда потратил, покупает. Переиспользует паттерны Phase 5-6 UI (composables, sheets, labels).

## Definition of Done

- Страница credits: баланс (крупно), история транзакций (grant/spend/refund/purchase)
- Покупка: ввод количества (или подсказка 10/30/100) → авто-сумма (calculatePrice 7.4) → заявка
- Статус заявки (pending/confirmed/rejected)
- Блок создания Event при 0 → сообщение + переход к покупке
- Русские названия типов транзакций
- Только owner/organizer
