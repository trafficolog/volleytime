# Epic 7.3: Credit spend при создании Event + refund

**Цель.** Создание Event списывает 1 credit (блок если баланс 0). Отмена Event до открытия записи возвращает credit (refund). После открытия — credit потрачен.

## Контекст

Решения 1, 3: spend при создании, refund до открытия записи, жёсткий блок при 0. Интеграция в eventService.create/cancel (Phase 5).

«Открытие записи» — момент когда первый игрок записался (или статус published + время). Уточняется в задаче.

## Definition of Done

- eventService.create: проверка баланса > 0, иначе блок (insufficient_credits)
- Успешное создание → spend transaction (−1), атомарно с Event
- eventService.cancel: если запись НЕ открывалась → refund (+1)
- Если запись открывалась (были брони / прошёл порог) → credit НЕ возвращается
- Блок при 0: понятная ошибка → UI ведёт к покупке
- Атомарность (Event + credit в одной транзакции)
