# Epic 9.7: Бэкапы (pg_dump → S3, cron, restore test)

**Цель.** Ежедневный автоматический pg_dump → Selectel Object Storage (S3). Ретенция. Обязательный тест восстановления (бэкап без проверки = нет бэкапа).

## Контекст

Решение 7: pg_dump → S3, ретенция 14-30 дней, тест восстановления. Данные (записи, оплаты, ledger) критичны — потеря = катастрофа. Бэкап должен быть проверен реальным восстановлением.

## Definition of Done

- Скрипт pg_dump (gzip) контейнера postgres
- Cron (host или cron-контейнер): ежедневно
- Upload в S3 (Selectel Object Storage), креды через env
- Ретенция: удаление старше N дней (14-30)
- Тест восстановления: скачать бэкап, восстановить в чистую БД, проверить данные
- Документирована процедура восстановления (runbook)
