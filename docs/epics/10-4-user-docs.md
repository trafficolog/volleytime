# Epic 10.4: User-facing документация (FAQ)

**Цель.** Минимальная пользовательская документация: FAQ организатора (создать событие/план/принять оплату/вести кассу) и игрока (записаться/абонемент/отмена). Короткие гайды.

## Контекст

Решение 7: user docs снижают нагрузку на поддержку. Бета-организаторы и игроки должны разбираться сами по основным сценариям. На основе реального опыта Трека B (что спрашивали).

## Definition of Done

- FAQ организатора: создание организации, события, плана, приём оплаты, касса, attendance, отмена события
- FAQ игрока: запись, выбор оплаты/абонемента, лист ожидания, отмена, мои абонементы
- Формат: доступно из Mini App (страница помощи) или /help бота ссылается
- Короткие, по сценариям (не исчерпывающий мануал)
- Опц: gif/скриншоты ключевых действий
- Русский язык
