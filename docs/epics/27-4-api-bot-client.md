# Epic 27.4: API, бот и клиент

**Цель.** API ограничивает частоту и фиксирует чувствительные действия; бот надёжно экранирует данные и доставляет уведомления; клиент не грузит лишнего.

## Контекст

Фаза [27](../phases/27-audit-hardening.md). Источник — [аудит 2026-11-10](../operations/reviews/2026-11-10-project-audit.md), разделы 2.4–2.6 (API, BOT, UI-SEC).

## Definition of Done

- Мутирующие и токенные маршруты ограничены по частоте.
- Чувствительные действия (роли, исключение, деньги, экспорт, владение) пишутся в журнал.
- Экранирование HTML в боте — одна функция с тестами.
- Скрипт Telegram загружается только в Mini App.
