# Epic 4.7: UI (Mini App + Web)

**Цель.** Реализовать все UI-страницы для Phase 4 операций: списки, формы создания, карточки, управление членами, invites, audit log. Параллельно для Mini App (`/m/*`) и веб-кабинета (`/orgs/*`).

## Контекст

Дизайн-референсы:

- https://volleytime.trafficolog.ru/mini-app.php (Mini App, 7+5 экранов)
- https://volleytime.trafficolog.ru/web-saas.php (Web SaaS, 7+6 экранов)
- https://volleytime.trafficolog.ru/brand-system.php (Brand & System)
- https://volleytime.trafficolog.ru/public-pages.php (Public)

Шрифты: Space Grotesk (заголовки) + Manrope (тело). Цвета: синий primary + оранжевый accent.

В Phase 4 не делаем все 12 экранов из референсов — только те, что относятся к Organizations/Members/Invites. События и абонементы — Phase 5+.

## Definition of Done

- **Mini App страницы** (под `/m/*`):
  - `/m/` — empty state или список организаций пользователя с переключателем
  - `/m/orgs/new` — форма создания организации
  - `/m/orgs/[orgId]` — dashboard организации (название, статистика members, последние audit события)
  - `/m/orgs/[orgId]/members` — список members с фильтром по роли/статусу
  - `/m/orgs/[orgId]/members/[memberId]` — карточка member (role change, block/unblock)
  - `/m/orgs/[orgId]/invites` — список invites + кнопка «создать»
  - `/m/orgs/[orgId]/audit` — audit log с фильтрами
  - `/m/orgs/[orgId]/settings` — настройки org (name, slug, default_member_status, archive)
  - `/m/invites/[token]` — accept invite page (видна без membership)
- **Web страницы** (параллельный набор под `/orgs/*`)
- **Public страница** `/o/[slug]` — заглушка с базовой info (no-auth, для shareable links)
- Применение токенов из brand-system (цвета, шрифты, spacing)
- Адаптивность: всё работает на мобильном и desktop
- Loading states / empty states / error states для всех страниц
- Permissions UI: кнопки/действия отображаются согласно правам (canX функции из 4.3)
- Composables: `useOrganization`, `useMembers`, `useInvites`, `useAudit`
