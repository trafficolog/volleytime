# Epic 10.6: Гейт-метрики + decision framework

**Цель.** Способ измерения гейт-критериев (как посчитать ретеншн, готовность платить, % через Mini App) и framework принятия решения (A/B/C сценарии) о переходе в Phase 7.

## Контекст

Решение 2, 8: обновлённые гейт-критерии (+ретеншн), переход в Phase 7 при успехе. Нужен объективный способ оценить «пройден ли гейт», а не на ощущениях.

## Definition of Done

- Метод измерения каждого гейт-критерия (откуда данные: super-admin обзор 10.3, опросы, наблюдение)
- Ретеншн: как считать «≥4 недели подряд» (события неделя-к-неделе per организатор)
- Готовность платить: как проверить (прямой вопрос + поведение)
- Decision framework: A (пройден→Phase 7) / B (частично→доработки) / C (провал→pivot) с порогами
- Чеклист гейт-ревью (провести в конце беты)
- Документ решения (зафиксировать итог + обоснование)
