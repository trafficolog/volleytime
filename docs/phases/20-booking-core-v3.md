# Phase 20: Запись и ядро v3

**Цель.** Игрок записывается на несколько мест и платит в Mini App; организатор создаёт событие и серию в кабинете; баланс событий, фоновые задачи и уведомления.

## Контекст

Первый релиз по референсу v3. Поглощает незапущенные фазы 7 (credits → баланс событий) и 15 (автоматизация): их карточки остаются входными материалами.

Источник — референс v3 (Ф1), импорт в [docs/design/reference-v3](../design/reference-v3/README.md); перепланирование — [19.0.1](../tasks/19-0-1-reference-v3-replan.md).

## Definition of Done

1. Игрок записывается на N мест, видит цену (fixed/split), очередь и отмену по политике группы
2. Организатор создаёт событие и серию в кабинете со списанием баланса событий
3. Фоновые задачи открывают/закрывают запись, финализируют split, напоминают; уведомления хранятся в ленте
4. Публичная страница события работает без входа
5. v0.2.0 выкачен через Promote и принят (20.7.1)
