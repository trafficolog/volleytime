# Phase 19: Фундамент v3

**Цель.** Дизайн-система v3, доменный контракт, настройки группы, уровни и права — база для всех экранов референса.

## Контекст

Переход проекта на целевой референс v3 (Claude Design export 2026-10-11/12). Код R0.7 уже содержит организации, события fixed/split, запись, абонементы, оплаты, кассу, Mini App и кабинет в стиле v2. Фаза закрывает разницу в фундаменте, не переписывая работающее.

Источник — референс v3 (Ф0), импорт в [docs/design/reference-v3](../design/reference-v3/README.md); перепланирование — [19.0.1](../tasks/19-0-1-reference-v3-replan.md).

## Definition of Done

1. Токены, ассеты, атомы и статусная модель v3 используются Mini App и кабинетом
2. ADR доменного контракта v3 принят, демо-сиды работают локально
3. Настройки группы и уровни В1–В4+ в API
4. Матрица прав покрывает новые ресурсы, IDOR-тесты зелёные
5. Решения владельца D-01…D-11 записаны
