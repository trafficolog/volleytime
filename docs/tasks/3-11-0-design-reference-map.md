# Task 3.11.0: Карта обновлённого дизайн-референса

## Цель

Зафиксировать конечное состояние дизайна v2, границу MVP и независимые SDD-задачи до изменения UI-кода.

## Контекст

Архив `Volley Time v2.zip` от 2026-09-23 содержит противоречащие друг другу ранний и финальный слои CSS, а также экраны будущих релизов. Без карты их легко принять за текущий MVP.

## Что должно быть сделано

1. Оформить [карту v2](../design/2026-09-23-reference-v2.md) с hash архива, токенами, screen matrix и границей scope.
2. Создать SDD-карточки для токенов, компонентов, auth, Mini App, desktop и приёмки.
3. Синхронизировать релиз-план и текущий статус как **план**, не как уже выполненную работу.

## Критерии приёмки

- Каждая MVP-группа экранов и 11 состояний auth отнесены к конкретной карточке.
- Root Admin и будущие функции явно исключены из этой итерации.
- Документация проходит Prettier и `git diff --check`; PR принят в `main`.

## Подсказки
