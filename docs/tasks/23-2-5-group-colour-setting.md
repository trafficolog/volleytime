# Task 23.2.5: Цвет группы в настройках организатора (`M-10`)

## Цель

У группы постоянный цвет, который выбирает организатор; он не меняется, когда игрок вступает в новые группы.

## Контекст

- **Как есть (main после PR #327, `b9ed7878`):** поля цвета у группы нет. Общий календарь берёт цвет по порядку групп игрока (сортировка по id) из токенов `--vt-group-1..4` (`apps/web/app/assets/css/tokens.css`, `groupColors` в `apps/web/app/utils/my-calendar.ts`); после четырёх групп цвета повторяются, при вступлении в группу с меньшим id цвета сдвигаются.
- `depends_on` остаётся `['23.2.2']`: экран настроек группы в кабинете уже существует, новая зависимость не нужна.
- Решение владельца 2026-11-22 в чате: возможность указать цвет в настройках организатором, положить в бэклог.

## Что должно быть сделано

1. Поле цвета группы (значение из фиксированной палитры токенов, не произвольный hex), аддитивная миграция (номер присваивается при реализации); контракт сначала задаёт `claude-opus-5-5` (правило 3 ORCHESTRATION).
2. Выбор цвета в настройках группы кабинета (права — как у остальных настроек группы).
3. Общий календарь использует сохранённый цвет; без выбранного цвета — текущее правило по порядку.

## Критерии приёмки

- Цвет группы в календаре игрока не меняется при вступлении в новые группы
- Палитра читается в светлой и тёмной теме
- Пять gates CODING_STANDARDS; ревью `claude-opus-5-5` без Critical/Important
