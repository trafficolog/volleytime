# Task 10.4.1: FAQ организатора + игрока (контент + страница в Mini App)

## Цель

Контент FAQ (организатор + игрок) + страница помощи в Mini App. Короткие гайды по сценариям. Доступно из /help бота и меню Mini App.

## Контекст

Решение 7: user docs снижают нагрузку на поддержку. На основе реального опыта Трека B (что спрашивали). Короткие FAQ по сценариям, не исчерпывающий мануал.

## Что должно быть сделано

1. **Контент FAQ организатора** (черновик, уточнить по опыту Трека B):

   ```
   ОРГАНИЗАТОР

   Как создать организацию?
   → Откройте приложение, «Создать организацию», укажите название и город.

   Как пригласить игроков?
   → В организации «Пригласить» → ссылка. Отправьте её в чат группы.
      Игроки переходят и присоединяются.

   Как создать тренировку?
   → «События» → «Создать». Укажите название, дату, место, вместимость,
      цену, дедлайн отмены.

   Как настроить абонементы?
   → «Абонементы» → «Создать план». Например «8 занятий за 80 BYN, 60 дней».
      Можно бесплатный план (цена 0).

   Как принять оплату?
   → Игрок записывается с «оплатой на месте». Вы получаете уведомление.
      В «Оплаты» подтверждаете → запись подтверждена, деньги в кассе.

   Как отметить кто пришёл?
   → На странице события «Записи» → отметьте «Был»/«Не был» → «Сохранить».

   Что в кассе?
   → Баланс, история доходов/расходов. Можно добавить расход (аренда, мячи).

   Как отменить событие?
   → На странице события «Отменить». Игрокам вернутся занятия/деньги,
      придёт уведомление.
   ```

2. **Контент FAQ игрока:**

   ```
   ИГРОК

   Как записаться на тренировку?
   → «События» → выберите → «Записаться». Выберите оплату:
      с абонемента или на месте.

   Что такое лист ожидания?
   → Если мест нет, вы встаёте в очередь. Если кто-то отменится —
      вы автоматически попадёте в состав и получите уведомление.

   Как купить абонемент?
   → «Абонементы» → выберите план → «Получить».

   Сколько занятий осталось?
   → «Мои абонементы» — остаток и срок действия.

   Как отменить запись?
   → «Мои записи» → «Отменить». Если был дедлайн отмены — успейте до него.
      Занятие вернётся на абонемент.
   ```

3. **Страница помощи `pages/m/help.vue`** (Mini App):

   ```vue
   <!-- табы: Организатор / Игрок -->
   <!-- аккордеон вопрос-ответ, по сценариям -->
   <!-- опц: gif/скриншоты ключевых действий -->
   ```

   Markdown-контент или структурированные данные → аккордеон.

4. **Связь с /help бота (8.3.2):** /help упоминает приложение, можно добавить ссылку на страницу помощи Mini App.

5. **Опц gif/скриншоты** — короткие гифки ключевых действий (создать событие, записаться). Не блокер, улучшение.

6. **Русский язык**, тон дружелюбный, кратко.

## Критерии приёмки

- ✅ FAQ организатора (создание org/события/плана, оплата, касса, attendance, отмена)
- ✅ FAQ игрока (запись, оплата/абонемент, waitlist, отмена)
- ✅ Страница помощи в Mini App (табы организатор/игрок, аккордеон)
- ✅ Доступна из меню Mini App
- ✅ Короткие гайды по сценариям (не мануал)
- ✅ Русский, дружелюбно
- ✅ Опц gif/скриншоты ключевых действий

## Подсказки

- **На основе Трека B** — что реально спрашивали при обкатке на своей группе. Это лучший источник «какие вопросы».
- **По сценариям, не по функциям** — «как записаться» лучше чем «описание кнопки записи». Пользователь думает задачами.
- **Аккордеон** — компактно, не пугает простынёй текста. Раскрыл нужное.
- **gif опционально** — сильно помогают, но требуют времени. Можно после запуска беты добавить по горячим вопросам.
