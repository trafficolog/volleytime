# Task 3.11.5: Доступность лендинга после review

## Дефекты

1. Акцентный `#ff6b1f` используется как текст и focus-outline на светлых поверхностях: контраст с белым около 2,85:1, с `--vt-bone` около 2,59:1. Это ниже порога 4,5:1 для обычного текста и 3:1 для крупного текста/индикатора фокуса. Тот же контраст имеет белый мелкий текст на оранжевой плашке демо-интерфейса. Декоративные оранжевые поверхности можно сохранить, но смысловой текст и фокус должны быть различимы.
2. На узких экранах CSS `order` переносит «Войти» и «Создать группу» перед ссылками разделов визуально, тогда как последовательность Tab остаётся по DOM: сначала разделы, затем действия.
3. При `prefers-reduced-motion: reduce` и coarse pointer наведение всё ещё сдвигает CTA на 2 px: правило сокращает длительность, но не отменяет transform.
4. При 320 px `overflow-x: clip` скрывает выход двух заголовков за правый край: измерение `Range.getClientRects()` дало правые границы 350 и 391 px при viewport 320 px, хотя `documentElement.scrollWidth` остаётся 320 px.
5. Финальное review исправлений обнаружило тёмную focus-обводку `#15161a` на синей карточке организатора `#1f2e96`: контраст 1,63:1, ниже порога 3:1. Ссылка «Создать группу» должна иметь светлый индикатор при клавиатурном фокусе.

## Критерии приёмки

- Смысловой акцентный текст на светлом и сером фоне проходит 4,5:1; крупный акцентный текст не ниже 3:1. Focus-индикатор различим на светлых и тёмных секциях, включая синюю карточку организатора (не менее 3:1), без потери видимости.
- Визуальный порядок мобильной навигации совпадает с Tab-порядком; все пять ссылок доступны и CTA не обрезан на 320/390/768 px.
- При reduced motion и coarse pointer hover CTA не вызывает пространственного сдвига; обычная мышь без reduced motion сохраняет эффект макета.
- Заголовки и смысловой текст на 320/390/768 px не обрезаются; проверять прямоугольники строк, а не один лишь `scrollWidth`.
- Для каждого исправления есть RED → GREEN проверка реального поведения; затем пять стандартных gates и browser QA. Изменения 3.11.4 не попадают в `prod` до общего R0.6 gate.
