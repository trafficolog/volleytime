# Task 21.4.8: Хвосты экранов игрока: статистика профиля и «Оплатить» в «Моих записях» (M-13)

## Цель

Довести профиль игрока и «Мои записи» в Mini App до макета: статистика посещений, строки «Язык», «Выйти», «Изменить» и кнопка «Оплатить» с реквизитами организатора.

## Контекст

- Хвосты [20.4.9](20-4-9-player-screens.md) были перенесены в backlog v0.3.0 решением владельца 2026-10-20 без владеющей карточки. Решение владельца 2026-11-10 ([журнал](../operations/decisions/2026-10-12-reference-v3-decisions.md), «Перенос хвостов игрока и кнопок бота в v0.3.1, одобрение diff workflow»): они переходят в `v0.3.1` этой карточкой. Сверка релиза v0.3.0 ([QA 21.3.1](../operations/qa/2026-11-10-21-3-1-release-v0-3-0.md)) принимает `3-miniapp-player/06` и `12` в объёме v0.3.0 со ссылкой сюда.
- Статус оплаты места в API игрока — [21.1.8](21-1-8-player-payment-status-api.md); способы оплаты и реквизиты группы — [21.2.11](21-2-11-settings-payment-methods.md) (только показ, решение 2026-11-06).
- Модель: реализация `claude-sonnet-5-5`, ревью `claude-opus-5-5` (оплата и данные игрока); маршрутизация — [ORCHESTRATION](../ORCHESTRATION.md).

## Что должно быть сделано

1. Профиль (`3-miniapp-player/06`): статистика игрока в текущей группе — посещения, посещаемость, no-show — по тем же правилам подсчёта, что у организатора ([21.2.20](21-2-20-players-stats-api.md)); только свои данные.
2. Строки «Изменить» (имя), «Язык» и «Выйти» по макету. Если переключение языка недоступно (интерфейс только на русском), строка показывает текущий язык без перехода; поведение «Выйти» в Telegram Mini App и в браузере описать в PR.
3. «Мои записи» (`3-miniapp-player/12`): кнопка «Оплатить» у записи с ожидающей оплатой ведёт на экран оплаты с реквизитами организатора (включённые способы группы, 21.2.11); без новых способов оплаты.
4. Тесты (RED→GREEN): статистика только своих данных, «Оплатить» только для ожидающей оплаты, выключенный способ не показывается, IDOR (чужая группа и чужая запись); сверка 19.0.2 по `reference.screens`.
5. Миграции не нужны; если окажутся нужны — остановиться и вернуть карточку оркестратору.

## Критерии приёмки

- ✅ Профиль показывает статистику и строки по макету; «Оплатить» ведёт к реквизитам организатора
- ✅ Игрок видит только свои данные; чужие группы и записи недоступны (IDOR-тесты)
- ✅ Схема и миграции не изменены
- ✅ Отчёт сверки 19.0.2 без открытых Critical/Important
- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-opus-5-5` без Critical/Important
