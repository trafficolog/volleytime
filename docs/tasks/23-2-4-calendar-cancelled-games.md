# Task 23.2.4: Отменённые игры в общем календаре (`M-10`)

## Цель

Игрок не теряет из виду отменённую игру, на которую был записан: она видна в общем календаре приглушённой, как в расписании группы.

## Контекст

- **Как есть (main после PR #327, `b9ed7878`):** `GET /api/me/calendar` (`packages/core/src/player-calendar`) исключает отменённые события; страница `apps/web/app/pages/m/orgs/[orgId]/calendar.vue` их не показывает.
- Расписание группы ([21.1.4](21-1-4-group-schedule.md)) показывает отменённые события приглушёнными — образец отображения.
- Решение владельца 2026-11-22 в чате, по вопросу ревью PR #327.

## Что должно быть сделано

1. API календаря возвращает отменённые события, на которые у игрока была запись (статус события в ответе); прочие отменённые события по-прежнему не возвращаются.
2. В списке и в месяце такая игра приглушена и помечена «Отменена», как в расписании группы.
3. Отменённая игра не участвует в пересечениях и не попадает в фильтр «С местами».
4. Переход в событие работает, как для остальных игр.

## Критерии приёмки

- Отменённая игра с записью игрока видна приглушённой; отменённая игра без его записи не видна
- Пересечения и «С местами» не учитывают отменённые игры
- Интеграционные тесты core/HTTP и тесты страницы; пять gates CODING_STANDARDS; ревью `claude-opus-5-5` без Critical/Important

## Не делать

- ❌ Не менять расписание группы и другие экраны
- ❌ Не показывать отменённые игры, на которые игрок не записывался
