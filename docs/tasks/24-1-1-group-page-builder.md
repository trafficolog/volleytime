# Task 24.1.1: Страница группы: конструктор (`W-13`)

## Цель

Организатор собирает SEO-страницу из секций.

## Контекст

- Спецификация референса: [W-13 · Страница группы · конструктор](../design/reference-v3/specs/03-organizer-web/W-13-group-page-builder.md); макет: 4 Кабинет организатора → Страница группы.
- **Как есть (main `e68acf2`):** Нет.
- **Дельта до референса:** Секции, порядок, предпросмотр, мета-теги, переключатель индексации.
- Модель: реализация `claude-sonnet-5-5`, ревью `claude-opus-5-5` (ревью Opus); маршрутизация — [ORCHESTRATION](../ORCHESTRATION.md).

**Общий функционал с другими интерфейсами:**

- **Уровни В1–В4+** — Один справочник для игроков, групп, составов и SEO. С этим связаны: [P-10 → 19.2.3](19-2-3-player-levels.md), [M-14 → 20.4.10](20-4-10-player-level.md), [W-06 → 21.2.2](21-2-2-players.md), [M-24 → 21.1.3](21-1-3-org-players-report.md), [M-18 → 25.1.3](25-1-3-skill-progress.md), [M-19 → 26.1.2](26-1-2-team-balancing.md), [M-15a → 26.1.3](26-1-3-ai-coach-agent.md). [Подробнее](../design/reference-v3/specs/links.md#levels)
- **Страница группы** — Конструктор организатора, рендер и модерация root. С этим связаны: [W-14 → 24.1.2](24-1-2-group-page-render.md), [R-06 → 24.1.3](24-1-3-group-page-moderation.md), [P-02 → 19.2.2](19-2-2-group-settings.md). [Подробнее](../design/reference-v3/specs/links.md#seo)

## Что должно быть сделано

Решение владельца 2026-11-22 — [D-24](../operations/decisions/2026-10-12-reference-v3-decisions.md#d-24).

**Шаги (правило 3 [ORCHESTRATION](../ORCHESTRATION.md#маршрутизация-моделей)):** контракт данных — `claude-opus-5-5` (схема, миграция, общие типы, сервис, API), затем UI — `claude-sonnet-5-5`. Отдельные PR; UI начинается после merge контракта.

1. Хранение: таблица `organization_group_pages`, одна строка на группу, миграция `0044` (аддитивная, с откатом); строки нет — страница по умолчанию. Рендер [24.1.2](24-1-2-group-page-render.md) читает ту же форму данных.
2. Раздел кабинета «Страница группы» со своим пунктом меню. Правка — только владелец (как настройки группы).
3. Секции: обложка (заголовок, подзаголовок, логотип группы без загрузки картинок), коротко о группе (свободный текст; город и район из настроек), расписание (автоматически, ближайшие 5 событий), форматы и уровни (уровни из настроек + свободный текст о форматах), цены (свободный текст), зал (один или несколько залов группы с адресами), как записаться (текст по умолчанию из режима записи, редактируемый), FAQ (вопрос/ответ, не больше 15).
4. Порядок и включение каждой секции.
5. Предпросмотр компьютер/телефон — лёгкий клиентский компонент, на котором строится 24.1.2.
6. Мета-теги: редактируемые title и description; title по умолчанию «<Название группы> — волейбол, <Город>»; проверки длины и наличия города — только предупреждения, сохранение не блокируют.
7. Переключатель индексации — в разделе «Страница группы», с подтверждением в обе стороны; хранится в существующем `organizations.seoIndex` (его читает и `/e/[slug]`, поведение не меняется). Из `SettingsProfile` переключатель убирается и заменяется ссылкой на раздел. `publicPageEnabled` остаётся за 24.1.2.

## Критерии приёмки

- ✅ Выключение индексации не влияет на режим записи
- ✅ Шаг контракта: GET/PUT страницы группы; не владелец получает 403, чужая группа недоступна (IDOR), лимиты дают 422; тест миграции и отката
- ✅ Шаг UI: раздел и пункт меню, секции, порядок и включение, предпросмотр, мета с предупреждениями, подтверждение индексации в обе стороны, ссылка вместо переключателя в `SettingsProfile`. Отчёт харнесса визуальной сверки не нужен (экранов референса нет, D-24); стиль — по экранам настроек кабинета 17–24
- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-opus-5-5` без Critical/Important
