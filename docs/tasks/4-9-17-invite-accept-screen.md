# Task 4.9.17: Экран приглашения: контекст группы, pending, «уже в группе», причина недействительности

## Цель

Экран принятия приглашения по дизайну «Mini App · приглашение».

## Контекст

Только название и город; для pending — «Вы присоединились!»; повтор — английская ошибка; недействительный — без причины.

## Что должно быть сделано

1. Preview API: число участников, до 5 аватаров, пригласивший (имя, роль), `myMembership` (если есть), причина недействительности (`revoked|expired|exhausted|not_found`) без 4xx-дампа.
2. UI: карточка группы, «Вас пригласил …», пояснение и две кнопки; pending → «Заявка отправлена, организатор рассмотрит»; уже участник → «Вы уже в группе → Открыть»; недействителен → причина + «Открыть мои группы».
3. Все тексты на русском.

- ✅ Четыре состояния экрана соответствуют дизайну
- ✅ Нет английских сообщений
