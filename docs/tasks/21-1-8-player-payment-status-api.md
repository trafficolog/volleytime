# Task 21.1.8: Статус оплаты в API игрока

## Цель

Игрок видит точный статус оплаты своих мест, в том числе освобождённых при отмене, и получает предупреждение «без возврата» только там, где место действительно оплачено.

## Контекст

- Решение владельца 2026-10-25 ([журнал](../operations/decisions/2026-10-12-reference-v3-decisions.md)): остаток [20.4.8](20-4-8-cancel-booking.md), которому не хватало API игрока, выделен в отдельную карточку v0.3.0.
- **Как есть (v0.2.0):** у игрока нет API с признаком `payments.seat_released_at`; список «Мои записи» отдаёт отменённые записи только для split. Предупреждение D-14 в подтверждении отмены показывается по способу оплаты (наличные или перевод), как в боте, поэтому может появиться и для неоплаченной записи.
- **Дельта:** API игрока отдаёт статус оплаты по местам своей записи (в том числе освобождённые места, `succeeded` + `seat_released_at`); UI использует его.
- Денежная модель — [ADR v3 · Денежная модель нескольких мест](../architecture/ADR-v3-domain.md#денежная-модель-нескольких-мест); решение D-14: автоматического возврата нет, возврат — действие организатора.
- Модель: реализация `claude-sonnet-5-5`, ревью `claude-sonnet-5-5` (независимое ревью); маршрутизация — [ORCHESTRATION](../ORCHESTRATION.md).

## Что должно быть сделано

1. API игрока: по своей записи отдавать статус оплаты мест (оплачено, ожидает, освобождено после оплаты) без чужих данных; только владелец записи.
2. История игрока («Мои записи», отменённые записи): строка «оплачено, место освобождено» для платежей `succeeded` с `seat_released_at`.
3. Предупреждение «без возврата» ([D-14](../operations/decisions/2026-10-12-reference-v3-decisions.md#d-14)) в подтверждении полной и частичной отмены — только для реально оплаченных мест; убрать приближение по способу оплаты в `player-booking-cancel.ts`.
4. Тесты: unit — проекция статуса и тексты; интеграционные — доступ только владельцу записи, освобождённое оплаченное место.

## Критерии приёмки

- ✅ Игрок видит «оплачено, место освобождено» для оплаченного освобождённого места
- ✅ Предупреждение «без возврата» не показывается для неоплаченных мест и показывается для оплаченных
- ✅ API не отдаёт данные чужих записей и платежей
- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-sonnet-5-5` без Critical/Important
