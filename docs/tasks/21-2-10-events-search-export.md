# Task 21.2.10: Поиск, фильтры, экспорт и пагинация «Показано N из M» в списке событий кабинета (`W-03`)

## Цель

Организатор находит событие в длинном списке, фильтрует его, постранично листает и выгружает список в CSV.

## Контекст

- Решение владельца 2026-10-14 (ревью PR #124, 20.5.4): поиск, фильтры, экспорт и пагинация вынесены из [20.5.4](20-5-4-events.md) отдельной задачей v0.3.0.
- Спецификация референса: [W-03 · События](../design/reference-v3/specs/03-organizer-web/W-03-events.md); макет: `4-cabinet/02-screen.png`, исходник — полоса фильтров («Все», «Открыта запись», «Прошедшие», «Отменённые» со счётчиком, «Фильтры», «Экспорт») и подвал «Показано N из M» со стрелками в `handoff/screens-web.jsx`.
- **Как есть (main `16b0cb8`):** `GET /api/organizations/{orgId}/events` без поиска и пагинации; вкладок-статусов и экспорта нет. Колонка «Оплаты» и меню строки — [20.5.8](20-5-8-events-payments-row-menu.md).
- **Дельта до референса:** серверные фильтры по статусу, периоду и тексту, пагинация со счётчиком «Показано N из M», CSV-экспорт отфильтрованного списка; фильтры сохраняются при переключении «Список / Календарь» (критерий 20.5.4).
- Модель: реализация `claude-sonnet-5-5`, ревью `claude-sonnet-5-5` (независимое ревью): экспорт содержит только поля событий и не включает суммы оплат и данные игроков; деньги в выгрузках — в [21.2.3](21-2-3-cashbox.md) и [21.2.7](21-2-7-reports.md). Если состав экспорта расширяется суммами или ФИО игроков, ревью переходит на `claude-opus-5-5`; маршрутизация — [ORCHESTRATION](../ORCHESTRATION.md).

## Что должно быть сделано

1. API списка: параметры статуса, периода, текстового поиска (название, зал), страницы и размера; в ответе `total` для «Показано N из M» и счётчики вкладок; сортировка стабильная.
2. Полоса фильтров: вкладки статусов со счётчиком, «Фильтры» (период, зал), поиск; состояние хранится в URL и сохраняется при переключении режимов.
3. Подвал «Показано N из M» и переходы по страницам с `aria-label`; пустой результат — пустое состояние с «Сбросить фильтры».
4. Экспорт: CSV текущего отфильтрованного списка (дата, название, зал, места, статус), без сумм оплат и персональных данных; формульные инъекции CSV нейтрализуются; имя файла с датой.
5. Сверить экраны с референсом через харнесс [19.0.2](19-0-2-visual-reference-harness.md) и приложить отчёт к PR.

## Критерии приёмки

- ✅ «Показано N из M» верно при любом фильтре; счётчики вкладок совпадают со списком
- ✅ Фильтры, поиск и страница сохраняются при переключении «Список / Календарь» и при перезагрузке (URL)
- ✅ CSV соответствует отфильтрованному списку, не содержит сумм и данных игроков; значения с `=`, `+`, `-`, `@` в начале экранированы
- ✅ Tenant safety: список и экспорт — только события своей группы; тест на чужую группу
- ✅ Тесты: API фильтров и пагинации (границы страниц, пустой результат, спецсимволы поиска), компонентные на полосу фильтров и подвал, на экспорт
- ✅ Отчёт визуальной сверки по экранам из `reference.screens` без открытых расхождений Critical/Important
- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-sonnet-5-5` без Critical/Important
