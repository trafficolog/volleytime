# Task 20.3.1: Фоновые задачи по событию (`P-04`)

## Цель

Автоматические переходы события по времени.

## Контекст

- Спецификация референса: [P-04 · Фоновые задачи по событию](../design/reference-v3/specs/01-platform/P-04-event-jobs.md); макет: поведение без отдельного экрана.
- **Как есть (main `e68acf2`):** Нет планировщика: запись закрывается вручную, split распределяется по действию организатора, напоминаний нет. Фаза 15 (pg-boss) расписана, не начата.
- **Дельта до референса:** Очередь с идемпотентными обработчиками (pg-boss по карточкам 15.x), открытие/закрытие записи по расписанию, финализация split, предложение места из очереди с TTL по D-03, закрытие отмены по политике группы, напоминания 24 ч / 2 ч. Новый воркер требует изменения compose и deploy runbook.

## Что должно быть сделано

1. Открытие и закрытие записи по расписанию
2. Финализация сбора суммой и выставление долей
3. Перевод из листа ожидания при освобождении места
4. Закрытие отмены по политике группы
5. Напоминания перед игрой
6. Данные и API: Очередь задач с идемпотентными обработчиками; Повтор при сбое, журнал выполнений.

- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-opus-5-5` без Critical/Important
- ✅ RED→GREEN тесты на граничные случаи, деньги/доступ и конкурентность приложены к PR
