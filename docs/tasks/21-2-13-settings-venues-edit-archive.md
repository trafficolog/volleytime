# Task 21.2.13: Залы и площадки: правка и архивирование (`W-11`)

## Цель

Организатор правит данные зала и убирает ненужный зал из выбора, не теряя историю событий.

## Контекст

- Решение владельца 2026-10-15 (ревью PR #138, 20.5.7): часть макета W-11, которой нужна новая серверная работа, выделена из [20.5.7](20-5-7-settings.md) отдельной задачей v0.3.0; в v0.2.0 она не входит.
- Спецификация референса: [W-11 · Настройки](../design/reference-v3/specs/03-organizer-web/W-11-settings.md); макет: 4 Кабинет организатора → Настройки → Залы и площадки, `4-cabinet/20-screen.png`; исходник — `WebSettings` в `handoff/screens-web.jsx`.
- **Как есть (main `35a43fd`):** API залов группы умеет только список и создание (`GET`/`POST .../venues`); у события `venue_id` стоит `ON DELETE SET NULL`.
- **Дельта до референса:** Меню зала: «Редактировать», «На карте», «Удалить». Решение карточки: зал, у которого есть события, не удаляется физически, а архивируется — иначе прошлые события потеряли бы зал. Зал без событий можно удалить совсем. Архивный зал скрыт из выбора при создании события и остаётся на прошлых событиях.
- Модель: реализация `claude-sonnet-5-5`, ревью `claude-opus-5-5` (ревью Opus: новые эндпоинты изменения данных группы, IDOR-тесты); маршрутизация — [ORCHESTRATION](../ORCHESTRATION.md).

## Что должно быть сделано

1. API: `PATCH` и `DELETE` зала группы; признак архива в схеме (миграция forward-compatible); `DELETE` на зале с событиями переводит его в архив и возвращает это в ответе, на зале без событий удаляет.
2. Выбор зала при создании события и серии не показывает архивные залы; прошлые и текущие события показывают прежнее название зала.
3. Подраздел «Залы и площадки»: форма правки (название, адрес, цена за час), меню зала, пометка архивного, подтверждение удаления с пояснением про архив; «На карте» открывает адрес во внешней карте.
4. Сверить экраны с референсом через харнесс [19.0.2](19-0-2-visual-reference-harness.md) и приложить отчёт к PR.

## Критерии приёмки

- ✅ Зал с событиями после «Удалить» архивирован и виден в прошлых событиях; зал без событий удалён
- ✅ Архивный зал нельзя выбрать для нового события; событие, уже ссылающееся на него, не ломается
- ✅ IDOR-тесты на `PATCH`/`DELETE` (чужая группа, чужой зал, роль без прав)
- ✅ Тесты: правка, архивирование, удаление, выбор зала в форме событий, компонентные на меню
- ✅ Отчёт визуальной сверки по экранам из `reference.screens` без открытых расхождений Critical/Important
- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-opus-5-5` без Critical/Important
