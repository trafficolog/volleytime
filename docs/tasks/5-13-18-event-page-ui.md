## Контекст

Нет площадки, заполненности, состава, отмены; после перезахода снова кнопки записи; повтор → английская ошибка; нет предупреждения о листе ожидания и варианта «перевод».

3. Ошибки через `apiErrorMessage` (русские тексты для `booking.*`).
