# Task 21.2.23: Сборы в кабинете: обещания и действия

## Цель

Дать организатору в кабинете работу со сбором: подтверждение и отклонение обещанных взносов и действия над самим сбором.

## Контекст

- Решение владельца 2026-11-05 ([журнал](../operations/decisions/2026-10-12-reference-v3-decisions.md), «Сборы в кабинете: обещания и действия»): [21.2.5](21-2-5-collections.md) поставляет только список и форму «Новый сбор» (PR #205); панель обещаний и действия над сбором вынесены сюда.
- Сервер уже есть ([21.2.4](21-2-4-collections-domain.md)): подтверждение и отклонение взноса (`confirm.post`, `reject.post`), правка (`index.patch`), завершение (`complete.post`), отмена (`cancel.post`). Карточка **только фронтенд**, серверных изменений нет.
- Экраны макета: `4-cabinet/11` (список) и `4-cabinet/12` (сбор с обещаниями).
- Модель: реализация `claude-sonnet-5-5`, ревью `claude-opus-5-5`; денежные действия подтверждения/отклонения — внимательное ревью (правило 1 [ORCHESTRATION](../ORCHESTRATION.md)).

## Что должно быть сделано

1. Панель обещаний на экране сбора (`4-cabinet/12`): список обещанных взносов с суммой, игроком и статусом; кнопки «Подтвердить» и «Отклонить». Ответ `409 payment.not_pending` (взнос уже обработан или заменён повторным обещанием игрока — повтор создаёт новый запрос) обрабатывать без падения: показать понятное сообщение и перезагрузить список.
2. Меню строки сбора в списке: «Изменить» (`index.patch`), «Опубликовать» для черновика, «Завершить» (`complete.post`), «Отменить» (`cancel.post`). Отмена и завершение — через подтверждение; текст отмены сообщает, что ожидающие обещания будут отклонены, а игроки получат уведомление.
3. Состояния и права: пункты меню по статусу сбора (черновик, идёт, завершён, отменён); действия доступны только управляющему; при выключенном флаге сборов поведение такое же, как в 21.2.5 (раздел скрыт/недоступен, без ошибок).
4. Тесты: компонентные/интеракционные — подтверждение и отклонение, обработка `409 payment.not_pending` и перезагрузка, меню по статусам, подтверждение отмены с предупреждением, выключенный флаг, ошибки сервера.
5. Сверка экранов `4-cabinet/11` и `12` харнессом [19.0.2](19-0-2-visual-reference-harness.md) (`qa:visual`), отчёт к PR.

## Критерии приёмки

- ✅ Организатор подтверждает и отклоняет обещания; после `409 payment.not_pending` список обновляется, ошибка не ломает экран
- ✅ Изменение, публикация черновика, завершение и отмена работают через существующие эндпоинты; отмена предупреждает об отклонении обещаний и уведомлении игроков
- ✅ Поведение при выключенном флаге согласовано с 21.2.5
- ✅ Серверный код и схема не изменены
- ✅ Отчёт визуальной сверки по `4-cabinet/11`, `12` без открытых расхождений Critical/Important
- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-opus-5-5` без Critical/Important

## Пробелы для бэклога 21.4.1

Макет показывает действия, для которых API нет; в эту карточку они **не входят** и передаются в бэклог огрехов [21.4.1](21-4-1-defects-collect.md) как пробелы: «Напомнить» (напоминание должникам), «В чат» (анонс сбора в Telegram-чат) и «Экспорт» (выгрузка обещаний). Если API для какого-то из них уже появился к началу работы — включить его в эту карточку.
