Ссылки и честные тексты 3.11.4 остаются рабочими; будущие функции не возвращаются.

## Что должно быть сделано

1. Hero: исходная сетка 1.05fr/1fr с gap 20 px; исходные отступы и типографика Oswald/Golos; синий блок с оранжевыми кругами, два декоративных телефона на desktop, один на mobile. Сохранять подпись «Пример интерфейса», заменить только неподдерживаемые данные и состояния, не упрощать визуальную плотность.
2. Полоса возможностей: оранжевый фон и исходный display-шрифт. «Было/стало»: серый чатовый блок и синий блок с карточкой события. Bento: исходная четырёхколоночная схема с двумя span-2 карточками, иконки SVG и иллюстрации; шесть визуальных карточек по тем же согласованным MVP-функциям: запись/очередь, оплаты, расписание, касса, абонементы, состав. Разделение прежних комбинированных карточек не добавляет будущих функций.
3. Шаги: inset серая секция с радиусом 40 px, белые карточки 28 px, номера 96 px. Аудитории: тёмный/оранжево-светлый блоки и списки. FAQ: серые скруглённые карточки. Финальный CTA: синий inset-блок 36 px с оранжевым кругом. Footer белый с исходной композицией, только действующие ссылки.
4. Сохранить функциональные контракты auth/CTA/FAQ/motion, reduced-motion/coarse-pointer, keyboard focus и исправления обрезки/порядка 3.11.5. Пользователь отдельно выбрал «Точное совпадение цветов; доступность обсудить отдельно»: текст и поверхности используют исходные цвета. Коричневый текстовый акцент 3.11.5 не переносится; прежние contrast-ожидания этого оттенка больше не являются критерием данной задачи. Известный контраст исходного оранжевого около 2,85:1 на белом остаётся открытым ограничением, не заявлять WCAG/color acceptance.
5. Browser RED выявил отдельную причину: Google Fonts не загружается, `document.fonts` пуст. Для лендинга поставлять те же Oswald 500/600/700 и Golos Text 400/500/600/700 локально с SIL OFL; не менять общую конфигурацию остальных экранов в этой задаче.
