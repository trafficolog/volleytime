## Контекст

- Спецификация референса: [W-14 · Страница группы · рендер](../design/reference-v3/specs/03-organizer-web/W-14-group-page-render.md); макет: 4 Кабинет организатора → Страница группы → предпросмотр.
- **Как есть (main `e68acf2`):** Нет.
- **Дельта до референса:** SSR, schema.org, sitemap, canonical, OG, каталог города, Lighthouse SEO ≥ 95. Логотип и короткую ссылку группы страница читает из [21.2.16](21-2-16-settings-logo-short-link.md) (v0.3.0): адрес `volleytime.by/<имя>` и логотип задаются там, здесь только рендер.
- Модель: реализация `claude-opus-5-5`, ревью `claude-opus-5-5` (ревью Opus + тесты граничных случаев и гонок); маршрутизация — [ORCHESTRATION](../ORCHESTRATION.md).

## Что должно быть сделано

1. Серверный рендер
2. schema.org: SportsActivityLocation, Event, FAQPage
3. index/noindex по seoIndex
4. sitemap.xml, canonical, OG
5. Каталог «Волейбол в {город}»
6. Гео-тексты для ИИ-поиска

7. Из ревью 24.1.1 (PR #324, #325): данные — `GET /api/organizations/{orgId}/group-page` и контракт `packages/shared/src/group-page/contract.ts`; предпросмотр `GroupPagePreview.vue` — основа рендера. Анонимному посетителю не отдавать этот ответ как есть: показывать ли события «по приглашению» и их `publicSlug` — решить при старте (рекомендация: не показывать; по решению 2026-10-19 они не индексируются); сохранённые `venueIds` пересекать с активными залами (архивный зал не показывать); секцию «Зал» без залов скрывать; сохранённые данные, не прошедшие схему, заменять секциями по умолчанию.
   - **Решено 2026-11-23** ([журнал](../operations/decisions/2026-10-12-reference-v3-decisions.md)): владелец — события «по приглашению» на публичной странице группы не показываются (ни в расписании, ни в schema.org). Умолчания: архивный зал скрыт; секция «Зал» без активных залов, пустые «Цены», FAQ, «Коротко о группе» и «Форматы» не рисуются; секция, не прошедшая схему, заменяется секцией по умолчанию своего вида, повтор и неизвестный вид отбрасываются, мета — по умолчанию. Анонимный ответ — отдельная проекция `GET /api/public/groups/{slug}` (`PublicGroupPageView`), не ответ конструктора.
   - Адреса: страница `/g/<slug>`, короткая ссылка `/<имя>` (21.2.16) — 302 на неё; каталог `/volleyball/<город>` («Волейбол в городе {город}», без склонения); `sitemap.xml`, `robots.txt`. Публикация `publicPageEnabled` — переключатель владельца в разделе «Страница группы».
