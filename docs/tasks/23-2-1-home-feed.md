# Task 23.2.1: Главная «Лента дня» (`M-03`)

## Цель

Главная показывает игру и только те функции, которые игрок оставил.

## Контекст

- Спецификация референса: [M-03 · Главная «Лента дня»](../design/reference-v3/specs/02-mini-app/M-03-home-feed.md); макет: 3 Mini App → Главная; 9 Гипотезы → Вариант A.
- **Как есть (main `e68acf2`):** Главная v3 из 20.4.4.
- **Дельта до референса:** Блок «Сегодня» по флагам, чип серии, ссылка «Лишнее на главной?».
- **Объём (решение владельца 2026-11-23, вариант (a), [журнал решений](../operations/decisions/2026-10-12-reference-v3-decisions.md)):** у блоков «Сегодня» (составы, разминка, «После игры», неделя тренера, итоги сезона) и чипа серии нет источников данных: карточки 26.1.2, 25.1.1, 25.1.2, 26.1.1, 26.1.4, 26.1.5 и 25.1.4 не сделаны. Здесь делается оболочка: подписка на `me-features`, чистая функция видимости блоков (флаг включён **и** данные есть), контракт слотов `apps/web/app/utils/home-blocks.ts`, ссылка «Лишнее на главной?» и состояния экрана. Блоки и чип серии без данных не рисуются, моков и заглушек нет; каждый блок подключает его карточка. Расхождения с референсом из-за отсутствующих блоков и чипа не считаются Critical/Important.
- Модель: реализация `claude-sonnet-5-5`, ревью `claude-opus-5-5` (ревью Opus); маршрутизация — [ORCHESTRATION](../ORCHESTRATION.md).

С этим связаны: [P-12 → 23.1.1](23-1-1-player-features.md), [M-02 → 20.4.2](20-4-2-tab-bar.md), [M-12 → 23.2.3](23-2-3-profile-features.md), [P-09 → 20.3.2](20-3-2-bot-notifications.md), [P-14 → 23.1.2](23-1-2-feature-analytics.md), [M-15b → 26.1.4](26-1-4-ai-coach-ui.md), [M-16 → 25.1.1](25-1-1-warmup.md), [M-17 → 25.1.2](25-1-2-self-check.md), [M-18 → 25.1.3](25-1-3-skill-progress.md), [M-19 → 26.1.2](26-1-2-team-balancing.md), [M-20 → 25.1.4](25-1-4-streaks.md), [M-21 → 26.1.1](26-1-1-mvp-vote.md), [M-22 → 26.1.5](26-1-5-season-wrapped.md). [Подробнее](../design/reference-v3/specs/links.md#features)

## Что должно быть сделано

1. Шапка: группа, уведомления; чип серии отложен до 25.1.4
2. Ближайшая игра (синий блок)
3. Плитки «Сессий осталось» (5 из 8) и «Мои записи» с шевроном
4. Блок «Сегодня»: оболочка и контракт видимости по флагам и данным (составы, разминка, «После игры», неделя тренера, итоги сезона подключают свои карточки); без данных блок и заголовок «Сегодня» не рисуются
5. Расписание и «Смотреть все»
6. Ссылка «Лишнее на главной? Выключите в профиле» ведёт на `/m/orgs/:orgId/features`; в режиме «Только игры» не показывается
7. Состояния экрана: Всё включено; Только игры (все флаги выкл.); Нет ближайшей игры; Нет абонемента.
8. Сверить экраны с референсом через харнесс [19.0.2](19-0-2-visual-reference-harness.md) и приложить отчёт к PR.

## Критерии приёмки

- ✅ Выключение функции убирает её блок без перезагрузки: видимость блока = флаг включён и данные есть (проверено тестами с подставленными данными; реальные данные блоков — в их карточках)
- ✅ В режиме «Только игры» и при отсутствии данных нет пустых заголовков
- ✅ Отчёт визуальной сверки по экранам из `reference.screens` без открытых расхождений Critical/Important, кроме отсутствующих блоков «Сегодня» и чипа серии (решение владельца 2026-11-23)
- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-opus-5-5` без Critical/Important
