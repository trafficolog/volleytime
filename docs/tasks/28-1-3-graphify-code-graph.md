# Task 28.1.3: Граф кода (AST, локально) и базовая оценка

## Цель

Построить граф кода без LLM и понять, полезен ли он на этом репозитории.

## Контекст

- Настройка — [28.1.2](28-1-2-graphify-install-config.md). AST-режим работает локально, данные не уходят с машины ([28.1.1](28-1-1-graphify-evaluation.md)).

## Что должно быть сделано

1. Построить граф только кода (`apps/`, `packages/`, скрипты) без семантического прохода: в окружении нет `ANTHROPIC_API_KEY` и других ключей backend, интеграция с ассистентом не установлена.
2. Повторить проверку `graph.json` из [28.1.2](28-1-2-graphify-install-config.md): секреты, IP-адреса, имена хостов VPS, пути `docs/operations` — ноль совпадений.
3. Записать базовую линию в guide: версия, время сборки, число узлов и рёбер, языки, что не разобралось (например, `.vue`).
4. Пять контрольных вопросов с известным ответом (например: путь от эндпоинта записи на событие до таблицы, кто вызывает расчёт баланса, где проверяется initData) — `graphify query|path|explain`; сравнить с ответом по коду. Оценка: верно / частично / неверно.
5. Вывод в карточке: стоит ли продолжать 28.1.4–28.1.5.

## Результат (2026-11-20)

Подробности и таблицы — [guide, «Базовая линия»](../guides/graphify.md#базовая-линия-2813-2026-11-20).

- Сборка: `graphify 0.9.103`, `GRAPHIFY_BACKEND=none`, ключей и `AWS_*`/`OLLAMA_*`/`AZURE_*` в окружении нет; `graphify extract . --code-only --no-cluster` (17 с), затем `graphify cluster-only . --no-label --no-viz` (4 с). `--no-label` не вызывает LLM, поэтому сообщества и `GRAPH_REPORT.md` получены локально. Не запускались: `install`, `--project`, `claude install`, `hook install`, `add`, `prs`, `clone`, `label`, Cloud, экспорты в графовые БД.
- Объём: 8759 узлов, 21710 рёбер (19744 в отчёте), 406 сообществ, 98% рёбер EXTRACTED. Не разобраны 73 `.sql` и 319 файлов без символов (в основном тесты). `.vue` разобраны штатно (2402 узла).
- Контрольные вопросы: 2 верно (путь эндпоинта записи до таблицы `bookings`, места проверки `initData`), 2 частично (вызывающие `getBalance` и `bookingService.cancel` — список импортёров сервиса с лишними), 1 неверно (`promoteFromWaitlist` — методы объектов-сервисов не являются узлами).
- Проверка `graph.json`: секреты, IPv4, имена хостов, `docs/operations`, `.env`, пути ключей — 0; `PASSWORD` 24 (только имена ключей), e-mail 4 (ложные `пакет@версия`); случайных строк 0.
- `graphify-out/` в `.gitignore`, в коммит не входит.
