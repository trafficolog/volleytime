## Что должно быть сделано

Решение владельца 2026-11-22 — [D-25](../operations/decisions/2026-10-12-reference-v3-decisions.md#d-25).

**Шаги (правило 3 [ORCHESTRATION](../ORCHESTRATION.md#маршрутизация-моделей)):** контракт данных — `claude-opus-5-5` (схема, миграция, общие типы, сервис, API), затем страница отчёта Root Admin — `claude-sonnet-5-5`. Отдельные PR; UI начинается после merge контракта. Ревью обоих шагов — `claude-opus-5-5`.

1. События открытия и использования функции: таблица `feature_events` (игрок, функция из восьми флагов `PLAYER_FEATURES`, вид `open`/`use`, сутки UTC, время), миграция `0045` (аддитивная; откат отказывает, пока есть события). Приём — `POST /api/me/feature-events`; одно событие вида на игрока, функцию и сутки, повтор не пишется. Из-за дедупликации `use` означает «пользовался в этот день», а не число использований.
2. Событие `open` шлёт календарь игрока (`/m/orgs/[orgId]/calendar`); остальные функции подключают события в своих карточках (их экранов ещё нет).
3. Хранение 180 дней; очистка — шагом планировщика.
4. Отчёт `GET /api/platform/feature-analytics` — только Root Admin, только агрегаты по платформе (без игроков и групп); когорта меньше 10 игроков скрывается. Метрики на функцию: доля выключивших (`user_features`), активные за 7 дней, удержание (когорта — первое открытие в окне [now−56d, now−28d), более ранние открытия не учитываются; доля тех, кто записался на игру в следующие 28 дней после него), частота записей за 28 дней с включённой и выключенной функцией. Совокупность всех метрик — игроки платформы (активные участники живых групп: не архивных и не удалённых); записи считаются только в живых группах. Если выключивших или включённых меньше 10, скрываются доля выключивших и обе стороны частоты (иначе малую сторону можно вычислить вычитанием или умножением).
5. Шаг UI: страница отчёта в разделе Root Admin по этому ответу.

## Критерии приёмки

- ✅ Для каждой гипотезы есть метрика успеха и отчёт
- ✅ Шаг контракта: приём событий без сессии — 401, функция или вид вне списка — 422, повтор за сутки не пишется; отчёт: без сессии 401, не root (в том числе администратор группы) — 403 `forbidden.root_only`; когорта меньше 10 — `null`; события старше 180 дней удаляются планировщиком; тест миграции и отката
- ✅ Шаг UI: страница отчёта Root Admin по ответу контракта
- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-opus-5-5` без Critical/Important
