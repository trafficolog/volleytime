# Task 20.4.11: Позиция в листе ожидания

## Цель

Игрок видит своё место в очереди: «В очереди · N-й», а при предложении места — срок подтверждения.

## Контекст

- Задача добавлена оркестратором по ревью 19.1.2: компонент `VtMyChip` принимает `waitPos`, но API позицию не отдаёт, поэтому чип показывает просто «В очереди».
- **Как есть:** лист ожидания — записи `waitlisted` в порядке `booked_at`; после 20.1.2 очередь может содержать места (`waitlist_seats`), после 20.3.1 — предложения с TTL 30 мин (D-03).
- **Перенесено из 20.4.5 (решение владельца 2026-10-19):** позиция в очереди в карточке события и лист ожидания из макета `3-miniapp-player/02-screen.png`. Уточнено владельцем 2026-10-20 ([D-03](../operations/decisions/2026-10-12-reference-v3-decisions.md#d-03), «Позиция в очереди (20.4.11)»): (a) игрок видит только свою позицию и число людей (записей) в очереди, без имён; поимённый лист — только организатору, вне этой карточки; (b) «ожидают N» считает людей, не места; (c) при местах в основе и в очереди — «Иду · +1 в очереди · 2-й»; (d) на закрытом или прошедшем событии — «Не попали» без позиции.
- Модель: реализация `claude-sonnet-5-5`, ревью `claude-opus-5-5` (порядок очереди и доступ); маршрутизация — [ORCHESTRATION](../ORCHESTRATION.md).

## Что должно быть сделано

1. Сервер вычисляет позицию игрока в очереди события по правилу ADR (порядок постановки, учёт мест) и отдаёт её в ответах события и «Мои записи» только самому игроку.
2. При активном предложении места — абсолютный срок подтверждения (D-03) в тех же ответах.
3. Mini App передаёт позицию в `VtMyChip` (`waitPos`) на главной, в событии и в «Мои записи»; при предложении — действие «Подтвердить до HH:MM».
4. Сверить экраны с референсом через харнесс [19.0.2](19-0-2-visual-reference-harness.md) и приложить отчёт к PR.

## Критерии приёмки

- ✅ Позиция совпадает с порядком продвижения очереди сервером (тест на отмену впереди стоящего)
- ✅ Игрок не видит позиции и данных других игроков (IDOR)
- ✅ Отчёт визуальной сверки по экранам из `reference.screens` без открытых расхождений Critical/Important
- ✅ Пять gates CODING_STANDARDS на tested revision; ревью `claude-opus-5-5` без Critical/Important
