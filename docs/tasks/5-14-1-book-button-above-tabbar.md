# Task 5.14.1: Кнопка «Записаться» над таб-баром, отступ контента, скрытие при MainButton

## Цель

Игрок может записаться на событие из браузера и из Telegram.

## Контекст

Панель `fixed bottom-0` без `z-index` перекрывается таб-баром; клик уходит в навигацию.

## Что должно быть сделано

1. Панель действия: `z-30` (над таб-баром `z-20`), отступ снизу на высоту таб-бара и `env(safe-area-inset-bottom)`.
2. В Telegram (`isTelegram`) панель не рендерится — действие уже на MainButton.
3. Нижний padding страницы учитывает панель, чтобы состав не прятался под ней.
4. Регрессия: тест `elementFromPoint` не автоматизируем — фиксируем проверку в QA-чеклисте (ширины 360/390/414).

## Критерии приёмки

- ✅ В браузере клик по «Записаться» открывает выбор способа оплаты
- ✅ В Telegram видна только MainButton

## Подсказки

- Высота таб-бара — 52 px + safe-area.

## Не делать

- ❌ Не использовать `!important` вместо порядка слоёв
