# Decisions

Зафиксированные продуктовые/стратегические решения с обоснованием.

Формат: `YYYY-MM-decision-name.md`

Примеры:

- Гейт-решения (beta-gate, см. runbook beta-gate-review)
- Pivot-решения
- Крупные архитектурные развилки

Цель — не терять контекст «почему так решили» при возврате через месяцы.
