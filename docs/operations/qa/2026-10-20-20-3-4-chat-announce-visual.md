## Сообщение

Макет (`BotMsg`, `keyboard={[['Записаться'], [{ label:'Открыть тренировку', app:true }]]}`):

```text
Ср · 28 мая · 20:00            (жирный)
Основа · Школа №24 · 15 Br
Свободно 5 из 14 мест.         (приглушённый)
[ Записаться ]
[ Открыть тренировку ]
```

Реализация (`buildEventAnnouncement`, HTML-подмножество Telegram: `b`, `i`; пользовательские строки экранируются):

```text
<b>Ср · 27 мая · 20:00</b>
Основа · Школа №24
<i>Свободно 5 из 14 мест.</i>
[ Записаться ]            url https://t.me/<бот>?startapp=event_<id>
[ Открыть тренировку ]    url https://t.me/<бот>?startapp=event_<id>
```

| Элемент макета                            | Реализация                                                                                         | Итог                                        |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| Строка даты «Ср · 28 мая · 20:00»         | День недели с заглавной, число и месяц, время — в часовом поясе группы (тест: Минск и Владивосток) | совпадает                                   |
| Строка «Название · Место»                 | `название · зал`; без зала — название группы                                                       | совпадает (цена — см. расхождения)          |
| «Свободно N из M мест.»                   | считается по занятым местам события (`takenSeats`); при отсутствии мест — «Мест нет.»              | совпадает                                   |
| Кнопки «Записаться», «Открыть тренировку» | Две строки, подписи как в макете; обе — `url`-ссылки (`web_app` в групповых чатах не работает)     | совпадает по составу, тип кнопок — см. ниже |
| Время абсолютное, без таймеров            | Дата фиксирована в тексте, живого счётчика нет                                                     | совпадает                                   |

## Расхождения с макетом

- **Minor / по карточке:** в макете вторая кнопка — `app:true` (открывает Mini App внутри Telegram), в групповом чате Telegram такие кнопки не поддерживает. Обе кнопки — `url`-ссылки `t.me/<бот>?startapp=event_<id>` (пункт 6 карточки); обе ведут на событие, где игрок записывается. Граница бота отклоняет `web_app` и `callback_data` для групповых чатов (тест `internal-server.test.ts`).
- **Minor / по карточке:** в строке места нет цены («15 Br» в макете): цена события зависит от режима (фиксированная, делёж суммы, места игрока), расчёт — задача 20.1.1; карточка 20.3.4 требует дату, место и «Свободно N из M». Цена видна в Mini App по ссылке.
- **Вне карточки:** кнопки действий над записью («Не смогу», «Беру место») в групповой чат не попадают — остаются в личном чате.

Critical/Important расхождений нет.

## Проверено автоматически

- Текст и клавиатура анонса: дата в часовом поясе группы, «Свободно N из M мест.» / «Мест нет.», экранирование названия, только `url`-кнопки (`announcement.test.ts`, `service.integration.test.ts`).
- Анонс уходит только в привязанный действующий чат группы события; событие чужой группы — 404, черновик, отменённое и начавшееся — отказ; недействительная или снятая привязка не доходит до бота (`service.integration.test.ts`, `telegram-chat-link.integration.test.ts`).
- Ошибки Bot API: исключение бота, нет права писать, перенос в супергруппу (400 с `migrate_to_chat_id`) и лимит 429 превращаются в понятные коды без токенов (`send-failure.test.ts`, интеграционные тесты).

## Осталось владельцу (Telegram QA на устройствах, см. [20.7.1](../../tasks/20-7-1-release-v0-2-0-qa.md), п. 11)

- Бот добавлен в групповой чат, администратор отправляет `/link <код из кабинета>`: ответ «Чат привязан…», команда с кодом удалена; от обычного участника и от анонимного администратора — отказ.
- Анонс приходит с датой, местом, «Свободно N из M», обе кнопки открывают нужное событие (для этого у бота в BotFather настроено основное Mini App).
- Исключение бота из чата снимает привязку (`released.reason = bot_removed`), возвращение бота её не оживляет; лишение права писать помечает привязку недействительной (`no_rights`) и снимается возвращением права (виден в `GET /api/organizations/{orgId}/telegram-chat`).
- В группе `/games`, `/my`, `/start`, `/menu`, `/help` отвечают одной строкой-подсказкой без кнопок; в меню команд личного чата они есть, в группах для администраторов — только `/link`.
