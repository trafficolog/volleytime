## Differences

- **Minor:** у пунктов меню нет иконок (в макете `globe`, `copy`, `send`, `close`): `VtPopover` 19.1.x иконок не поддерживает, расширение вне карточки.
- **Minor:** в макете вся строка кликабельна и открывает карточку; в кабинете карточка открывается по названию (поведение 20.5.4, не менялось), поэтому «клик по меню не открывает карточку» выполняется тривиально.
- **Minor:** в макете «ждёт оплаты» — число платежей с иконкой; здесь сумма в BYN («+30,00 BYN»): карточка требует сумму ожидающего оплаты, формат денег проекта.
- **Minor:** текст подтверждения отмены общий (состав в списке не загружен): «Все записи… отменены, игроки получат уведомление. Оплаты вернутся… Баланс событий вернётся, если запись ещё не открывалась или в событии нет ни одной записи». Подробный счёт по местам остаётся в карточке события (20.5.6).
- **Minor, вне карточки:** строка поиска, «Фильтры», «Экспорт», пагинация «Показано N из M», колонка «Статус» с цветными чипами «Запись/OK»: 21.2.10 и статусная модель 19.1.2 (как в QA 20.5.4).
- Снимки меню сняты на `d369767`; после них изменён только текст пунктов подтверждения отмены (убрана строка «Состав не загружен»), интеракционный тест страницы проверяет итоговый текст.
