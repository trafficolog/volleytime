## Ограничения сверки

- Смотрели глазами снимки в обеих темах; pixel-diff только ориентир. Референс — превью 924×540, размеры брались из исходников `screens-web.jsx` (`WebEventDetail`).
- Данные демо-сида для сверки изменялись только в локальной БД: у одной записи 3 места («+2»), две записи в листе ожидания (одна на 2 места), у записи в основе дополнительное место в очереди, одна запись на абонементе; для второго прогона событие переведено в «сбор суммой» (120,00 BYN) и вместимость поднята до 20, иначе занято мест больше вместимости, а расчёт цены на такое состояние отвечает 500 (искусственное состояние данных, не сценарий продукта).
- Не снимались: отменённое событие (цена скрыта; покрыто интеракционным тестом `card.interaction.test.ts`), событие после начала (кнопки «Был / Не пришёл», покрыто тестами), диалог отмены (покрыт интеракционным тестом: текст последствий, запрос только после подтверждения). Живой клик с записью в БД (подтверждение оплаты, отмена события) не выполнялся: действия проверены тестами с моком `$fetch`, серверная часть покрыта интеграционными тестами 20.2.1 и платежей.
- Скринридер вручную не прогонялся; доступность проверена ролями и именами (`alertdialog`, `aria-label` у иконочных кнопок, `role="img"` у шкалы оплат).
- Интеграционные тесты `packages/core/src/events` (отмена с возвратом, расчёт цены): 101 из 107 прошёл; 6 падений — `split-rollback-*`, их защитный контракт требует заранее разрешённого транспорта PostgreSQL («transport identity is unproven»), к этой карточке не относятся.

## Differences

- **Minor:** кнопки действий в строке состава (подтвердить / отклонить оплату, «Был», «Не пришёл», снять) — иконки с `title` и `aria-label`, а не текстовые кнопки: в двух колонках места на подписи не хватает. В макете действий в строке нет (только статус).
- **Minor:** «Отменить событие» и «Изменить событие» стоят в шапке страницы; «Дублировать» и «В чат» макета не реализованы (нет API; дублирование и меню строки — карточка 20.5.8).
- **Вне карточки:** «Журнал» макета (нет API журнала события), кнопка «Добавить» игрока вручную (нет API), «Credit −1 (списан …)» (баланс события не отдаётся в ответе), «Напомнить неоплатившим» (нет API).
- Метка «закрытие вручную» (20.3.1, PR #153): в «Параметры» вместо времени закрытия; на снимках не снималась (проверена тестом), на демо-событии метки нет.
- **Расчётная особенность (не расхождение):** первая колонка долей «сейчас» равна верхней границе ответа `GET …/price` с `seats=1`; если у организатора есть собственная запись, сервер вычитает её места из занятых (см. `quoteEventPrice`), поэтому число мест в колонке может быть меньше занятых мест события.

Critical: нет. Открытых Important нет.
