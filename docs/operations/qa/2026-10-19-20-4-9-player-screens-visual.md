## Расхождения (Minor, приняты)

1. **Профиль: блок статистики** (24 тренировки / 96 % посещаемость / no-show) отсутствует: игроку нет API со статистикой, моковые числа не переносились. Кнопка редактирования профиля, «Язык», «Выйти из аккаунта» и «Напоминания» не перенесены: у них нет серверной функции в v0.2.0 (настройки отключения типов — 23.1.1). Сохранены реальные «Личные данные» и «Уровень в группе».
2. **Абонементы:** нет номера `#SUB-0143` (в модели нет такого идентификатора), нет меню «Поделиться абонементом» (передача — вне объёма), в истории вместо шкалы фактического остатка — нейтральные сегменты по числу занятий.
3. **Покупка:** нет чипа «Популярный» (нет данных), второй способ оплаты — «Переводом» с текстом «Реквизиты уточните у организатора» (реквизитов в API нет); «Картой онлайн» — «скоро» без подписи «Phase 12». Заголовок «Выберите абонемент» вместо «Чем больше — тем дешевле каждая»: это утверждение верно не для всех планов организатора. Нижняя кнопка закреплена над таб-баром (sticky), а не над ним отдельной полосой.
4. **Мои записи:** на сегментах нет счётчиков (для них нужен второй запрос); кнопки «Оплатить» нет — реквизитов нет в API; позиция в листе ожидания не показывается (задача 20.4.11), вместо неё «Вы в очереди · уведомим». Лист ожидания вынесен в раздел «В листе ожидания» с кнопкой «Выйти из листа ожидания». «Прошедшие» используют ту же карточку, что «Предстоящие» (в референсе — компактные строки), на снимках референса этой вкладки нет.
5. **Уведомления:** кнопки действий на карточках («Подтверждаю / Не смогу», «Хочу войти / Пас», «Купить») не реализованы: подтверждения явки в продукте нет, а принятие места и отмена доступны с экрана события, куда ведёт карточка. Тексты карточек строятся из `payload` ленты по шаблонам бота.
6. **Сборы** не входят: перенесены в 21.1.6.
7. Таб-бар: Главная / Абонементы / Профиль (решение владельца 2026-10-14); на экране покупки вкладка «Абонементы» остаётся активной.
8. Рамка Telegram отсутствует вне Telegram (ожидаемо).

## Ограничения сверки

- Не снимались: пустая лента («Всё прочитано»), ошибка загрузки, догрузка страницы, раздел «В листе ожидания», абонементы выключены; покрыты интерактивными тестами `notifications.interaction.test.ts`, `bookings.interaction.test.ts`, `subscriptions/*.interaction.test.ts`.
- Chromium only; Firefox и Safari, reduced motion и safe-area визуально не проверялись.
- Лента проверена на пяти вручную добавленных записях; запись в ленту создаёт 20.3.2, здесь не менялась.
