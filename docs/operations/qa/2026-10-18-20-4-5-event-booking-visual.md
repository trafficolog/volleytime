## Расхождения (Minor, приняты)

1. «Бронь сохранится 15 мин» из `03-screen.png` не показана: для наличных и перевода серверного срока брони нет (TTL — только для онлайн-оплаты, Phase 12, карточка 15.6.1 поглощена). Вместо этого — «Место закрепляется за вами сразу. Оплату подтвердит организатор вручную». Нужно решение владельца, если 15 мин нужны.
2. Ветка очереди без выбора оплаты (как в референсе): абонемент в очереди больше не выбирается, при переходе в состав платёж наличными (D-03 C).
3. Позиция в очереди («В очереди · N-й») не показывается: сервер её не отдаёт, 20.4.11.
4. Лист ожидания поимённо (референс) не показан: игроку API отдаёт только число мест в очереди.
5. Карточка предложения стоит под составом; на высоте 820 px кнопка частично под таб-баром до прокрутки (в Telegram действие на MainButton).
6. Шрифты и рамка устройства референса отличаются (превью 924×540); размеры взяты из исходников.
