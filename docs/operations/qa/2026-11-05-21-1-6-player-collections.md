## Решение владельца 2026-11-05: видимость вкладки «Сборы»

- Вкладка скрыта при `capabilities.collections = false`, если в группе нет сборов; если сборы есть, вкладка показана для просмотра (экраны только для чтения, с плашкой «Приём взносов сейчас приостановлен»).
- **Выбранный вариант:** флаг берётся из уже загружаемого ответа группы. Дополнительный запрос `GET …/collections?limit=1` выполняется только при выключенном флаге (при монтировании layout и смене группы), при включённом флаге запросов нет. Ошибка запроса — вкладка остаётся скрытой. Организаторам запрос не делается.
- Прямые ссылки на `/m/orgs/{id}/collections…` работают всегда, в режиме только чтения (страницы от вкладки не зависят).
- Точка новой вкладки остаётся на устройстве, текст кнопки «Заменить обещанный взнос» сохранён (инженерные значения по умолчанию).
- Тесты layout: флаг выключен без сборов (вкладки нет), флаг выключен со сборами (есть), флаг включён (есть, без доп. запроса), ошибка запроса (нет).

## Поведение, проверенное тестами взаимодействия

- Повторный взнос: на экране взноса при ожидающем обещании показана плашка «У вас уже есть обещание на … Новый взнос заменит его: прежняя заявка будет отменена, а организатор получит новую», форма предзаполнена прежними суммой и способом, кнопка «Заменить обещание»; после ответа `replaced: true` тост «Обещание заменено на … · ждём подтверждения». На экране сбора кнопка «Заменить обещанный взнос».
- Флаг `COLLECTIONS_ENABLED` (`capabilities.collections`): при `false` экраны читаются, вместо кнопки взноса и в форме — плашка «Приём взносов сейчас приостановлен», отправка заблокирована. Ответ `collection.disabled` на отправку: сообщение, форма блокируется, переход не выполняется. `collection.not_active` и `collection.not_found` перечитывают сбор и показывают закрытое состояние.
- Дедлайн только отображается («до 28 октября», «осталось N дн.», «срок прошёл»); после срока кнопка взноса остаётся, пока организатор не закроет сбор (решение владельца 2026-10-28).
- Точка новой вкладки: горит до первого открытия (в том числе при заходе напрямую на экран сбора), затем нет; без доступа к хранилищу не показывается.
