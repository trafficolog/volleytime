# QA Mini App в реальном Telegram (Task 8.8.11)

Что нельзя проверить автотестами: initData, темы, системные кнопки, доставка уведомлений, deeplink из чата.
Прогонять на **iOS**, **Android** и **Telegram Desktop** перед каждым релизом; результат фиксировать в таблице ниже.

**Окружение:** staging-бот, тестовая группа, два аккаунта — организатор и игрок.

## Сценарии

| #   | Сценарий                                         | Ожидаемый результат                                                      | iOS | Android | Desktop |
| --- | ------------------------------------------------ | ------------------------------------------------------------------------ | :-: | :-----: | :-----: |
| 1   | `/start` в боте → кнопка «Открыть Volley Time»   | Mini App открывается, вход без экрана логина                             |     |         |         |
| 2   | Открыть Mini App вне Telegram (браузер)          | Редирект на вход по email, после входа — возврат в `/m/`                 |     |         |         |
| 3   | `/start org_<token>` по ссылке приглашения       | В чате название группы и пригласивший; кнопка ведёт на экран приглашения |     |         |         |
| 4   | Отозванная/просроченная ссылка                   | Бот объясняет причину, приложение показывает причину и «Мои группы»      |     |         |         |
