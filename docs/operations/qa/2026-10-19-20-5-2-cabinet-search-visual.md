## Differences

- **Minor:** в макете показано только поле; вид выдачи (группы, подписи строк, «Есть ещё — уточните запрос») собран по токенам v3 и спецификации P-13 («результаты сгруппированы по типу»).
- **Minor:** у игрока нет отдельной страницы, строка игрока ведёт в список «Игроки»; платёж — в «Оплаты» (страницы платежа нет). Переходы по `id` добавит карточка, которая создаст эти страницы.
- Выдача — не более 8 строк на тип; признак `more` показывает «Есть ещё — уточните запрос». Поиск по подстроке без учёта регистра (имя, `@ник`, название события и зала, название абонемента); ранжирования по релевантности нет.
