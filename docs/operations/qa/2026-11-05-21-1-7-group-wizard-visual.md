## Решение владельца 2026-11-05

Группа создаётся на переходе 1→2 (предпросмотр серии требует существующей группы с балансом); шаг 3 создаёт серию; «Назад» со шага 2 группу не отменяет; повтор и «Назад → Дальше» не создают вторую группу. Шаблон серии: название = группа, 120 минут, тип «тренировка», weekly на месяц от завтрашнего дня по часам группы.

## Раунд ревью

- Ключ идемпотентности серии — один на запуск мастера; 409 `series.idempotency_conflict` ведёт на шаг 3 с пометкой «Расписание уже создано»; после неоднозначной ошибки пропуск не заявляет «расписание позже»; ошибка гаснет при изменении полей. Тесты: ключ не меняется при правке расписания, 409 → шаг 3, «Далее» заблокирована пока предпросмотр грузится, системная «назад» Telegram на шаге 2; интеграционный: повтор с тем же телом — replay, другое тело с тем же ключом — 409, баланс не изменился, одна строка `event_series`.
- Чипы дней по прототипу (ink на paper выбранный, `--vt-ctl` невыбранный); заголовок шага 3 — `sr-only` с фокусом.
