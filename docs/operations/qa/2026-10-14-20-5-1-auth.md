## Расхождения с макетом (Minor, осознанные)

- Код входа — одно поле `autocomplete="one-time-code"`, а не 6 ячеек макета: сохраняет автозаполнение и работу скринридера.
- Срок кода — «5 минут» (как в `packages/auth/src/config.ts`), в макете «10 минут»; счётчик попыток макета («осталось 2») не показывается: сервер их не сообщает.
- Экран загрузки без вымышленного чек-листа («Код подтверждён…»): только реальный статус.
- Ссылки «Помощь» и «Условия» из футера не добавлены: страниц нет.
- Кнопка «Открыть бота в Telegram» (нет доступа) — тёмная `vt-btn--ink`, а не `--vt-tg-blue`: белый текст на `#2AABEE` не проходит контраст 3:1, а README разрешает этот цвет только кнопке входа.
- Кнопка «Войти через Telegram» — наша (`vt-btn--ink` с иконкой), не iframe Telegram: стилизуется токенами и проходит контраст; вызывает `Telegram.Login.auth` (popup). Не `--vt-tg-blue` с белым текстом: контраст ниже 3:1.

## Ограничения проверки

- Виджет Telegram **не проверен вживую**: нужен реальный бот с `/setdomain` для домена и доступ к `telegram.org`; это шаги владельца (см. карточку). Проверены тестами: загрузка скрипта только при включённом флаге, кнопка появляется лишь когда есть `Telegram.Login`, вызов `Telegram.Login.auth({ bot_id, request_access: false })`, отсутствие `data-auth-url` и `data-onauth` (в том числе в исходниках), цепочка callback → `POST /api/auth/sign-in/telegram-widget` → сессия (integration-тест с подписью тестовым токеном).
- Почему не `data-onauth`: `telegram-widget.js` превращает эту строку в функцию через eval, а CSP без `'unsafe-eval'` её блокирует (виджет молча не работал бы). CSP-тест `caddy-csp-contract.test.ts` фиксирует: нет `unsafe-eval`, `script-src` содержит `telegram.org`, `connect-src` — `'self'` и `https://oauth.telegram.org`.
- Caddy CSP: добавлен `https://oauth.telegram.org` в `connect-src` (fallback XHR виджета). `frame-src` не нужен: popup-поток не встраивает iframe. Пока флаг выключен, поведение не меняется; применяется при выкатке Caddyfile.
- Ручная проверка владельцем после деплоя (staging-подобный запуск, флаг включён, `/setdomain` выполнен): открыть `/auth/login` → кнопка «Войти через Telegram» видна → клик → popup Telegram → подтверждение → редирект в кабинет, в браузере есть сессия; в консоли нет CSP-нарушений; при закрытии popup ошибки нет; при выключенном флаге кнопки нет.
- Размер окна харнесса 1440×900; мобильная ширина вручную не снималась (контейнер `max-width: 360px`, поля 28 px).
- Pixel-diff — ориентир: референс — превью 924×540 с рамкой.
