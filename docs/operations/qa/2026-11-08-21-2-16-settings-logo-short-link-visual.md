## Совпадает с макетом

Подраздел «Профиль» первый в меню настроек. Над формой профиля — блок «Логотип и короткая ссылка»: квадратная плитка 64 px с логотипом (без логотипа — монограмма), кнопка «Загрузить логотип» с подсказкой «PNG или JPEG, до 512 КБ», поле «Короткая ссылка» с серой приставкой `volleytime.by/` слева и полем ввода справа. Обе темы читаемы, горизонтального скролла нет.

## Сквозной сценарий (проверен в браузере)

1. SVG отклоняется в браузере до запроса: «Нужен файл PNG или JPEG (SVG не поддерживается)».
2. Выбор PNG показывает предпросмотр в плитке; «Сохранить логотип» грузит файл (multipart) и показывает его из `/api/organizations/{id}/logo?v=…`; появляются «Заменить логотип» и «Удалить».
3. Ответ логотипа: `Content-Type: image/png`, `X-Content-Type-Options: nosniff`, `Content-Security-Policy: default-src 'none'; sandbox`, `Cache-Control: private, no-cache`, `ETag` по версии.
4. Адрес `admin` отклоняется: «Это слово занято приложением», `VT-Minsk` сохраняется как `vt-minsk` и остаётся после перезагрузки страницы.
5. Mini App: логотип в шапке «Обзор группы» и в шторке «Мои группы», у других групп остаются монограммы.
6. «Удалить» возвращает монограмму.

## Изменения по решениям владельца 2026-11-09

Логотип читается без входа (публичный GET, public-кэш на 5 минут, один 404 для «нет логотипа / нет группы / неверный id»). Короткую ссылку меняет только владелец: организатор видит поле только для чтения с пояснением «Менять короткую ссылку может только владелец группы», логотип по-прежнему меняют владелец и организатор. При вводе адреса владелец сразу видит статус предпроверки (проверяем / свободен / занят / занято приложением / формат), кнопка «Сохранить ссылку» блокируется для занятого, зарезервированного и неверного адреса; 409 при сохранении остаётся для гонки. Поведение покрыто компонентными тестами (debounce, устаревший ответ, сбой подсказки) и HTTP-тестами; визуальная раскладка карточки не менялась, добавлена строка статуса под полем.

## Проверка занятости
