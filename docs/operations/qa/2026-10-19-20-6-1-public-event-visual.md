## Differences

- **Minor:** прогноз split — цена для места следующего игрока (`сумма ÷ (занято + 1)`, 21,00 BYN при 9 местах), а в макете делится на текущий состав (≈ 23,33). Так требует карточка: цена только из `quoteEventPrice`, совпадает с `GET …/price`. Итог закрытого сбора совпадает с макетом по формуле (210 ÷ 9 = 23,34 с округлением вверх).
- **Minor:** таблица «n игроков → сумма» показывает три сценария из ответа расчёта (текущий, +2, полный состав), а не фиксированные 9/11/12/14.
- **Minor / по карточке:** вместо имён «Артём, Никита, Маша» — инициалы и «и ещё N» (персональные данные без согласия не раскрываются). Инициалы на наложенных аватарах частично перекрыты, как в макете.
- **Вне карточки (нет данных/API):** блоки «Как добраться», «Что взять», «Оплата», «Правила записи», QR-код события, «поддержка / политика конфиденциальности» не реализованы.
- Заголовок длинного названия может заходить на оранжевый круг hero (белый на оранжевом, крупный текст).

## Ограничения сверки

- Смотрели глазами снимки в обеих темах; pixel-diff только ориентир (референс — превью 924×540 с рамкой окна).
- Не снимались: отменённое событие, «по приглашению», «запись откроется», событие со «мест нет» — покрыты тестами (`public-event.test.ts`, `PublicEventPage.interaction.test.ts`, интеграционные тесты API).
- Telegram и реальный бот не проверялись: ссылка проверена по формату (`t.me/<bot>?start=event_<id>`); открытие Mini App на устройстве — Telegram QA владельца.
- Скринридер вручную не прогонялся; шкала мест — `role="img"` с подписью, иконки декоративные.
- Кеш-заголовки и `X-Robots-Tag` проверены `curl` на dev-сервере (индексируемая группа: без заголовка, `robots: index, follow`); `noindex` при `seoIndex=false` — тестом `indexable` и по коду страницы.
- Лимит запросов (429) проверен unit-тестом middleware; поведение за Caddy с `TRUSTED_PROXY=1` на стенде не проверялось.
- Интеграционные тесты миграций: откат 0030 отказывает при живых событиях (тест), старые миграционные тесты проходят через помощник `rollbackPublicSlug`.
