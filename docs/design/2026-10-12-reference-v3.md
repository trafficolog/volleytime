# Volley Time v3 — карта дизайн-референса

> Задача [19.0.1](../tasks/19-0-1-reference-v3-replan.md), 2026-10-12. Заменяет [карту v2](2026-09-23-reference-v2.md) как источник целевого UI для новых работ; карта v2 остаётся историей R0.6–R0.7.

Источник: [docs/design/reference-v3](reference-v3/README.md). Референс v3 — целевой: экраны Mini App (игрок и организатор), кабинета организатора, Root Admin, публичных страниц, авторизации, бота и гипотез. Правила, расходящиеся с выкаченным R0.7, — в [журнале решений](../operations/decisions/2026-10-12-reference-v3-decisions.md).

## Что изменилось относительно v2

| Область                                       | v2 (реализовано в R0.6–R0.7)                         | v3                                                                                                                                                  |
| --------------------------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Токены                                        | палитра Bento Bold, радиусы, отступы до 32           | шкала шрифтов `--fs-2xs…--fs-7xl`, отступы 40/48, `--r-xs/--r-sm/--r-pill`, токены текста на hero, оверлеи и тени, нейтральная `--vt-shadow-accent` |
| Логотип                                       | PNG                                                  | SVG-знак «Галочка-подача» и комплект (favicon, apple-touch, on-blue, on-orange)                                                                     |
| Атомы                                         | кнопки, карточки, чипы, поля, шит, таб-бар           | + `VtSelect`, toggle, popover, alert, toast, сегмент-пилюля, паттерны гипотез                                                                       |
| Статусы                                       | полный статус события (8.10.7)                       | три оси, которые не смешиваются: участие · событие · места; оплата — отдельная ось                                                                  |
| Запись                                        | одно место, автопродвижение очереди                  | несколько мест (`maxSeats`), «+N», предложение из очереди с TTL 30 мин                                                                              |
| Событие                                       | одно событие, срок отмены у события                  | серии (`RecurrenceBlock`), режим записи с наследованием, политика отмены группы, баланс событий                                                     |
| Mini App                                      | игрок и организатор v2                               | стек навигации, BackButton/MainButton, переключатель групп, сборы, лента уведомлений, расписание на месяц                                           |
| Кабинет                                       | shell, события, состав, абонементы, касса, настройки | поиск ⌘K, плашка баланса, сборы, отчёты и экспорт, баланс и оплата, уведомления, 8 подразделов настроек                                             |
| Root Admin, публичные страницы, SEO, гипотезы | не входили                                           | целевые в фазах 22–26                                                                                                                               |
