# W-17 · Настройки → Команда

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Кабинет организатора | Ф2 · Кабинет, Mini App организатора, Root Admin | M | Sonnet | Opus |

## Цель

Владелец управляет ролями, тренерами и правом принимать оплату.

## Макет

- 4 Кабинет → Настройки → Команда
- 4 Кабинет → Игроки → ··· → Роль в команде

## Объём

- Таблица: человек, роли, что ведёт, приём оплаты (переключатель у тренеров)
- Приглашение в команду по ссылке на 24 ч
- Сделать тренером / организатором, назначить на серию, убрать из команды (остаётся игроком)
- Матрица «Что доступно роли»
- История изменений ролей

## Данные и API

- P-18 members API

## Критерии приёмки

- [ ] Только владелец видит раздел
- [ ] Передача владения — только через «Опасную зону»

## Правки после ревью

- У человека может быть несколько ролей (например, тренер и игрок); колонка «Что ведёт» показывает серии тренера, переключатель приёма оплаты — только у тренеров.
