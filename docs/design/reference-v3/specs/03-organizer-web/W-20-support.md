## Цель

Команда группы ведёт обращения по работе кабинета в одном разделе.

## Макет

- 4 Кабинет → Поддержка
- 4 Кабинет → Поддержка → Новое обращение

## Объём

- Пункт меню «Поддержка» в блоке «Платформа»
- Слева — обращения команды группы (кто создал, тема, статус, время), справа — переписка или форма нового
- Статьи базы знаний для организатора под списком
- Форма: тема, «Коротко», «К чему относится», подробности, файл, подсказка статьи; контекст — организация, раздел, браузер

## Состояния экрана

- Нет обращений — пустое состояние со ссылкой на базу знаний
- Есть ответ — точка непрочитанного в меню

## Критерии приёмки

- [ ] Тренер видит только свои обращения, владелец — все обращения группы
