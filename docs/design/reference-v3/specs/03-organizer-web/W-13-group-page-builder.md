## Цель

Организатор собирает SEO-страницу из секций.

## Макет

- 4 Кабинет организатора → Страница группы
- 4 Кабинет организатора → Страница группы → инспектор «SEO» → Город
- Скриншоты: `screenshots-2026-11-24/4-cabinet/32-W13-vybor-goroda.png`, `33-W13-poisk-goroda.png`

## Объём

- Секции: обложка, коротко о группе, расписание, форматы и уровни, цены, зал, как записаться, FAQ
- Порядок и включение секций
- Предпросмотр компьютер/телефон
- Мета-теги и проверки
- Переключатель индексации с подтверждением
- Город — из каталога 24.1.2 (все районные центры, ≈120): выпадающий список с поиском, сгруппирован по Минску и областям, у каждого города виден адрес (`/pinsk`). Пустой поиск — подсказка выбрать ближайший город
- Предложный падеж для H1 и title считается из названия («в Пинске», «в Барановичах»), исключения — словарём
- Адрес `volleytime.by/{город}/{группа}`; смена города или slug — 301 со старого адреса
- Title и description: «Авто» по шаблону или «Свой»; ключевые запросы с подсказками
- Инспектор: вкладки «Секция · SEO · Проверка N/M»
- Баннер решения модерации root (R-06): причина, дата, «Запросить проверку», «Ответить модератору»

## Критерии приёмки

- [ ] Выключение индексации не влияет на режим записи
- [ ] При принудительном noindex от root переключатель индексации заблокирован и объясняет почему
- [ ] Баннер модерации совпадает с сообщением в боте
- [ ] Поиск города находит любой из ≈120 районных центров без учёта «ё»
