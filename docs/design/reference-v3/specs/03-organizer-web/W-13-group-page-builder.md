# W-13 · Страница группы · конструктор

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Кабинет организатора | Ф4 · SEO-страницы групп | L | Sonnet | Opus |

## Цель

Организатор собирает SEO-страницу из секций.

## Макет

- 4 Кабинет организатора → Страница группы

## Объём

- Секции: обложка, коротко о группе, расписание, форматы и уровни, цены, зал, как записаться, FAQ
- Порядок и включение секций
- Предпросмотр компьютер/телефон
- Мета-теги и проверки
- Переключатель индексации с подтверждением

## Критерии приёмки

- [ ] Выключение индексации не влияет на режим записи
