|---|---|---|---|---|

## Цель

Выручка, аренда и заполняемость по тренерам, залам и сериям.

## Макет

- 4 Кабинет → Отчёты → «В разрезе»

## Объём

- Переключатель: по тренерам / залам / сериям
- Колонки: игр, заполняемость, выручка, аренда

## Критерии приёмки

- [ ] Суммы сходятся с итогом месяца
