# W-18 · Долги и ограничения записи

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Кабинет организатора | Ф2 · Кабинет, Mini App организатора, Root Admin | M | Sonnet | — |

## Цель

Организатор работает с должниками и нарушителями, а не только видит колонку «Задолж.».

## Макет

- 4 Кабинет → Игроки → блок «Долги» и «Правила записи»
- 4 Кабинет → Игроки → ··· → Ограничить запись

## Объём

- Долги: список, «Напомнить» (с реквизитами), «Отметить оплаченным», «Списать», «Напомнить всем»
- Правила группы: не пускать с долгом выше N; заморозка после N неявок подряд
- Ограничения игрока: по одобрению, заморозка на 14 дней, блок в группе; заметка организатора

## Критерии приёмки

- [ ] Списание пишется в кассу отдельной категорией
- [ ] Ограниченный игрок видит причину на экране записи
