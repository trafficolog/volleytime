# W-14 · Страница группы · рендер

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Кабинет организатора | Ф4 · SEO-страницы групп | XL | Opus | Opus + тесты |

## Цель

Публичная страница, которую находят по «волейбол {город} тренировки».

## Макет

- 4 Кабинет организатора → Страница группы → предпросмотр

## Объём

- Серверный рендер
- schema.org: SportsActivityLocation, Event, FAQPage
- Итоговая индексация: `seoIndex` владельца и нет noindex от root (R-06)
- Скрытая root страница отдаёт тот же 404, что неопубликованная
- Адрес `volleytime.by/{город}/{группа}`, 301 со старых адресов
- Кнопка «Пожаловаться» с формой и лимитом (R-06)
- sitemap.xml, canonical, OG
- Каталог «Волейбол в {город}»
- Гео-тексты для ИИ-поиска

## Критерии приёмки

- [ ] noindex-страница отсутствует в sitemap и каталоге
- [ ] Lighthouse SEO ≥ 95
- [ ] Скрытая страница неотличима от несуществующей по ответу сервера
- [ ] Принудительный noindex попадает в meta robots и X-Robots-Tag

## Правки после ревью

- Адрес страницы с городом и две реакции root — «Скрыть» (404) и «Принудительный noindex» (24.1.3).
