## Цель

Часть вопросов закрывается статьёй ещё до обращения.

## Макет

- 3 Mini App → Новое обращение → «Возможно, ответ уже есть»
- 4 Кабинет → Поддержка → Новое обращение
- 10 База знаний → Статья → «Статья помогла?»

## Объём

- Подсказка статьи по выбранной теме и по словам в тексте обращения
- «Статья помогла? Да / Нет» на сайте; при «Нет» — переход в форму с заполненной темой
- События в аналитику (P-14): показ подсказки, переход в статью, обращение отправлено после подсказки, «помогла / не помогла»

## Критерии приёмки

- [ ] Подсказка не блокирует отправку обращения
- [ ] В отчёте видно, какие статьи чаще всего не помогают
