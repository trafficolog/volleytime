## Цель

Команда платформы пишет и обновляет статьи без разработчика.

## Макет

- нет макета — нарисовать: 4b Root Admin → База знаний

## Объём

- Разделы по ролям: игрокам, тренерам, организаторам; статья может быть в нескольких ролях
- Статья: заголовок, slug, раздел, текст с заголовками, списками, врезкой «Важно» и скриншотами, время чтения, дата обновления
- Статусы: черновик → опубликована → в архиве; предпросмотр черновика по ссылке
- Связанные темы обращений — для подсказок H-04

## Данные и API

- GET /kb/sections
- GET /kb/articles/{slug}
- POST/PATCH /admin/kb/articles

## Критерии приёмки

- [ ] Смена slug оставляет 301-редирект со старого адреса
- [ ] Архивная статья не попадает в поиск и подсказки
