# M-28 · Место из листа ожидания с ответом

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Mini App | Ф2 · Кабинет, Mini App организатора, Root Admin | M | Sonnet | — |

## Цель

Освободившееся место предлагается первому в очереди с таймером, без молчаливого продвижения.

## Макет

- 3 Mini App → Профиль → Место из листа ожидания

## Объём

- Таймер 30 минут (настройка группы), место держится
- «Беру место» → обычная запись; «Не смогу» → следующему, игрок остаётся в очереди
- Сообщение в бот с той же кнопкой

## Критерии приёмки

- [ ] По истечении таймера предложение уходит следующему автоматически
- [ ] Двое не могут получить одно место
