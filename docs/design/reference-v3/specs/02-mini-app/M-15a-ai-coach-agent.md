## Цель

Генерация персонального плана упражнений.

## Макет

- 9.1 AI-тренер

## Объём

- Вход: цель (подача, приём…), уровень, частота, инвентарь, ограничения
- Выход: план на неделю, упражнения с дозировкой
- Замена упражнения
- Ограничения безопасности: травмы, нагрузка, дисклеймер
- Кэш и лимит вызовов модели

## Данные и API

- POST /coach/plan
- POST /coach/exercise/replace

## Критерии приёмки

- [ ] План валидируется по схеме перед показом
- [ ] При сбое модели — шаблонный план с пометкой
