# M-03 · Главная «Лента дня»

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Mini App | Ф3 · Вариант A: личные функции и календарь | L | Sonnet | Opus |

## Цель

Главная показывает игру и только те функции, которые игрок оставил.

## Макет

- 3 Mini App → Главная
- 9 Гипотезы → Вариант A

## Объём

- Шапка: группа, чип серии, уведомления
- Ближайшая игра (синий блок)
- Плитки «Сессий осталось» (5 из 8) и «Мои записи» с шевроном
- Блок «Сегодня»: составы, разминка, «После игры», неделя тренера, итоги сезона — по флагам
- Расписание и «Смотреть все»
- Ссылка «Лишнее на главной? Выключите в профиле»

## Состояния экрана

- Всё включено
- Только игры (все флаги выкл.)
- Нет ближайшей игры
- Нет абонемента

## Критерии приёмки

- [ ] Выключение функции убирает её блок без перезагрузки
- [ ] В режиме «Только игры» нет пустых заголовков
