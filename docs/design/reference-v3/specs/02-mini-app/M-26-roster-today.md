# M-26 · «Состав сегодня»

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Mini App | Ф2 · Кабинет, Mini App организатора, Root Admin | L | Sonnet | Opus |

## Цель

Один экран на зале: кто пришёл, кто нет, приём оплаты. Общий для организатора и тренера.

## Макет

- 3 Mini App → Организатор → Главная → «Сегодня · Основа в 20:00»
- 3 Mini App → Организатор → Событие → ··· → Отметить пришедших
- 3 Mini App → Тренер → Состав

## Объём

- Счётчики: пришли, не пришли, не отмечены; «к оплате» — только с правом на оплату
- Строка игрока: уровень В1–В4+, места, три кнопки 40×40 «пришёл / опоздал / не пришёл»
- С правом на оплату: «не оплачено» или «говорит, что перевёл», кнопка «Принять / Подтвердить» → наличные или перевод
- Без права: сумм и статусов нет, подсказка «попросите включить приём оплаты»
- «Пришёл без записи»
- Сохранение отметок пакетом

## Данные и API

- P-19 attendance, P-20 payment-confirm

## Критерии приёмки

- [ ] Тренер без флага не видит ни одной суммы
- [ ] Подтверждение оплаты тренером видно в кассе как «на зале · тренер …»

## Правки после ревью

- Тренер попадает сюда из «Сегодня» → «Отметить пришедших» и из вкладки «Состав»; организатор — из «Сегодня · Основа в 20:00» на главной и из ··· события.
- В шапке кнопка «QR» → показать QR на экране или отправить в чат группы (M-31).
- Подтверждение оплаты — шторка «Получил наличными / Перевод пришёл»; в кассе запись «на зале · тренер …» (W-07).
