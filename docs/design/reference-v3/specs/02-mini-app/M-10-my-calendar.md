# M-10 · Общий календарь

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Mini App | Ф3 · Вариант A: личные функции и календарь | L | Sonnet | Opus |

## Цель

Все игры игрока из всех групп в одном месте.

## Макет

- 3 Mini App → Календарь
- 9 Гипотезы → Мой календарь

## Объём

- Месяц и список
- Цвет группы точкой
- Пересечения по времени
- Фильтр «Только мои» / «С местами»
- Переход в событие нужной группы

## Состояния экрана

- Нет записей в месяце
- Пересечение двух игр

## Критерии приёмки

- [ ] Данные из всех групп игрока одним запросом
