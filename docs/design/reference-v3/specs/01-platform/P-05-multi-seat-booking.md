# P-05 · Запись на несколько мест

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Платформа | Ф1 · Запись и ядро | XL | Opus | Opus + тесты |

## Цель

Игрок занимает до `maxSeats` мест в одной записи.

## Макет

- 3 Mini App → событие → выбор мест
- 4 Кабинет → карточка события → состав

## Объём

- Выбор числа мест при записи, ограничение `maxSeats` и свободными местами
- Если мест не хватает: часть в основу, часть в очередь — с явным выбором игрока
- Частичная отмена мест
- Отображение «+N» в составе

## Данные и API

- POST /events/{id}/bookings {seats}
- PATCH /bookings/{id} {seats}

## Критерии приёмки

- [ ] Конкурентные записи не превышают лимит мест (блокировка/транзакция)
- [ ] Освобождённые места уходят первым в очереди
