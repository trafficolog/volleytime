## Цель

Единая модель обращения в поддержку для игроков, тренеров, организаторов и посетителей без входа.

## Макет

- 3 Mini App → Профиль → Помощь и поддержка
- 4 Кабинет → Поддержка
- 4b Root Admin → Поддержка
- 10 База знаний → Написать в поддержку

## Объём

- Обращение: номер S-NNNN, автор, роль автора, организация (если есть), тема, канал (Mini App, кабинет, бот, сайт помощи), статус, исполнитель
- Сообщения: автор, текст, время, тип — сообщение пользователя, ответ поддержки, внутренняя заметка, системное
- Статусы: новое → в работе → есть ответ (ждём пользователя) → решено; пользователь может вернуть «решено» ответом в течение 7 дней
- Сроки: первый ответ — 4 рабочих часа, считается по часам работы из R-14; флаг «близко к сроку» за 1 ч, «просрочено» после срока
- Автозакрытие: «есть ответ» без реакции 3 дня → «решено», бот предупреждает за сутки
- Обращения организации видят владелец и тот, кто создал; игрок видит только свои
- Каждая смена статуса и исполнителя пишется в журнал (R-07)

## Данные и API

- POST /support/tickets
- GET /support/tickets?mine=1 · ?org={id}
- GET /support/tickets/{id}
- POST /support/tickets/{id}/messages
- POST /support/tickets/{id}/solve — пользователь закрывает сам
- PATCH /admin/support/tickets/{id} — статус, исполнитель, тема (root)

## Критерии приёмки

- [ ] Внутренняя заметка никогда не уходит пользователю и не видна в его API
- [ ] Счётчик срока не идёт вне часов работы
- [ ] Автозакрытие идемпотентно: повторный запуск задачи не шлёт второе предупреждение
- [ ] Номер обращения уникален и не меняется

## Примечания

- Жалобы на организатора и игрока (M-33, R-10) остаются отдельной сущностью; из обращения можно создать жалобу, но не наоборот.
