# P-10 · Уровни В1–В4+

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Платформа | Ф0 · Фундамент | M | Sonnet | — |

## Цель

Единая шкала уровней вместо A/B/C.

## Макет

- 4 Кабинет → Страница группы → уровни

## Объём

- Справочник: В1 полупрофи, В2 сильный любительский, В3 средний любительский, В4 продолжающие любители, В4+ начинающие — с описаниями
- Миграция существующих данных с A/B/C
- Уровень у игрока, группы (несколько), события

## Данные и API

- GET /levels
- Поле level в профиле игрока

## Критерии приёмки

- [ ] В интерфейсе нигде не осталось A/B/C
