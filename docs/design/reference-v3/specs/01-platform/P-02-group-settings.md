# P-02 · Настройки группы

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Платформа | Ф0 · Фундамент | M | Sonnet | — |

## Цель

Настройки уровня группы, которые задают поведение событий по умолчанию.

## Макет

- 4 Кабинет организатора → Настройки → Записи и оплата

## Объём

- `subsOn` — абонементы в группе включены/выключены
- `maxSeats` — мест на одного игрока, по умолчанию 3, диапазон 1–10
- `priceMode` по умолчанию: фиксированная цена или сбор суммой
- `joinMode` по умолчанию: свободная запись или по приглашению
- Политика отмены: разрешена ли, за сколько часов до начала закрывается
- `seoIndex`, город, район

## Данные и API

- GET/PATCH /groups/{id}/settings
- История изменений настроек (кто, когда, было/стало)

## Критерии приёмки

- [ ] Изменение настройки не меняет уже созданные события
- [ ] Новое событие получает значения группы по умолчанию
- [ ] Выключение абонементов скрывает их в Mini App и запрещает продажу новых
