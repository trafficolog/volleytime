# P-01 · Доменная модель

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Платформа | Ф0 · Фундамент | XL | Opus | Opus + тесты |

## Цель

Единая схема данных и контракт API, на которых строятся Mini App, кабинет и Root Admin.

## Макет

- все макеты

## Объём

- Сущности: организация (группа), участник и роль, событие, серия, запись, место в записи, лист ожидания, абонемент, план абонемента, сбор, операция кассы, баланс событий и его операции, приглашение, уведомление
- Связи и ограничения целостности: запись принадлежит событию и игроку, мест в записи ≥ 1
- Статусы события: черновик → запись открыта → запись закрыта → прошло / отменено
- Статусы записи: иду, в очереди (позиция), отменена, не пришёл
- Версионирование API, формат ошибок, пагинация

## Данные и API

- Схема БД и миграции
- OpenAPI-описание всех ресурсов
- Сиды демо-данных по макетам (VolleyTime Минск, МинскВолей, СпайкКлуб)

## Критерии приёмки

- [ ] Все экраны макетов получают данные из описанных ресурсов без «заглушек»
- [ ] Схема покрывает сбор суммой, несколько мест и серию без отдельных таблиц-костылей
- [ ] Миграции применяются и откатываются на пустой и на заполненной базе
