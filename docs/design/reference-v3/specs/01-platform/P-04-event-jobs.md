# P-04 · Фоновые задачи по событию

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Платформа | Ф1 · Запись и ядро | XL | Opus | Opus + тесты |

## Цель

Автоматические переходы события по времени.

## Макет

- поведение без отдельного экрана

## Объём

- Открытие и закрытие записи по расписанию
- Финализация сбора суммой и выставление долей
- Перевод из листа ожидания при освобождении места
- Закрытие отмены по политике группы
- Напоминания перед игрой

## Данные и API

- Очередь задач с идемпотентными обработчиками
- Повтор при сбое, журнал выполнений

## Критерии приёмки

- [ ] Повторный запуск задачи не создаёт двойных списаний и уведомлений
- [ ] Время считается в часовом поясе группы
- [ ] Перевод из очереди срабатывает в течение 1 минуты после отмены
