# R-10 · Жалобы

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Root Admin | Ф2 · Кабинет, Mini App организатора, Root Admin | M | Sonnet | — |

## Цель

Очередь обращений игроков и организаторов с действиями поддержки.

## Макет

- 4b Root Admin → Жалобы

## Объём

- Счётчики: новые, в работе, решено за 30 дней
- Фильтр открытые / решённые / все
- Действия: запросить объяснение (48 ч), зафиксировать возврат, предупреждение организации, закрыть без мер

## Критерии приёмки

- [ ] Каждое действие пишется в журнал
- [ ] Стороны получают ответ в бот

## Правки после ревью

- Здесь только жалобы игроков на организаторов из Mini App (M-33). Жалобы посетителей на публичные страницы групп — в «Страницы групп → Жалобы» (R-06), отдельная таблица.
- Права по [R-15](R-15-platform-team-roles.md): решение по жалобе — Owner, Admin, Moderator; Support видит жалобы и передаёт модератору.
