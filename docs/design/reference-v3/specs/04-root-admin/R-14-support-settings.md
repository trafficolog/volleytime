## Цель

Темы, шаблоны и сроки настраиваются без релиза.

## Макет

- нет макета — нарисовать: 4b Root Admin → Настройки → Поддержка

## Объём

- Темы обращений и для каких ролей они видны
- Шаблоны ответов: название, текст с подстановками {имя}, {группа}, {событие}, привязка к теме
- Часы работы по дням недели, срок первого ответа, срок автозакрытия
- Команда поддержки: кто видит очередь, кому назначать по умолчанию

## Критерии приёмки

- [ ] Изменения сроков применяются к новым обращениям, старые сохраняют свой срок
- [ ] Каждое изменение пишется в журнал
