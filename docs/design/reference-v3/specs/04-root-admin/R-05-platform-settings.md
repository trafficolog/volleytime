# R-05 · Настройки платформы

| Интерфейс | Фаза | Сложность | Модель | Ревью |
|---|---|---|---|---|
| Root Admin | Ф2 · Кабинет, Mini App организатора, Root Admin | L | Sonnet | Opus |

## Цель

Глобальные параметры.

## Макет

- 4b Root Admin → Настройки

## Объём

- Платформа
- Команда & роли: Owner, Admin, Support и матрица прав
- Feature flags
- Лимиты & квоты (в том числе лимит жалоб на страницы, R-06)
- Уведомления
- Биллинг
- Безопасность: 2FA обязательна для Owner и Admin
- API & вебхуки

## Критерии приёмки

- [ ] Изменения пишутся в журнал
- [ ] Support видит жалобы на страницы, но действия «Скрыть», «noindex» и «Вернуть» для него недоступны и в интерфейсе, и в API

## Правки после ревью

- Вкладки приведены к макету 4b.
- В матрицу прав добавлены строки: «Поддержка» — Owner, Admin, Support; «Жалобы игроков и на страницы» — Owner, Admin, Support; «Страницы групп: скрыть, noindex, вернуть» — Owner и Admin.
