# R-13 · Карточка обращения

| Интерфейс | Фаза | Эпик | Задача | Сложность | Модель | Ревью |
|---|---|---|---|---|---|---|
| Root Admin | Ф29 · Техподдержка и база знаний | 29.3 · Обработка в Root Admin | 29.3.2 | L | Sonnet | Opus |

## Цель

Ответить пользователю быстро и не переспрашивать.

## Макет

- 4b Root Admin → Поддержка → обращение

## Объём

- Переписка с внутренними заметками другим цветом
- Поле ответа с переключателем «Ответ пользователю / Внутренняя заметка», шаблоны ответов, вставка ссылки на статью
- Боковая панель: статус, исполнитель, тема, канал, срок; пользователь (Telegram, группы, тренировки) со ссылками в «Пользователи» и «Организации»; контекст из приложения; прошлые обращения
- Действия: взять в работу, передать, решено, создать жалобу (R-10) из обращения

## Критерии приёмки

- [ ] После ответа статус становится «есть ответ», если исполнитель не выбрал иное
- [ ] Вставленная статья открывается у пользователя на help.volleytime.by
