# R-06 · Модерация страниц групп

|---|---|---|---|---|
| Root Admin | Ф4 · SEO-страницы групп | M | контракт Opus, UI Sonnet | Opus |

## Цель

Контроль публичных страниц.

## Макет

- прототип владельца 2026-11-23: [`handoff/screens-moderation.jsx`](../../handoff/screens-moderation.jsx) — 4b Root Admin → «Страницы групп» (`ModCities`, `ModComplaints`), 5 Public Pages → «Пожаловаться» (`ModGroupPublic`), 4 Кабинет → баннер решения (`ModSeoBanner`); D-08 выполнено

## Объём

- Каталог городов: все районные центры и Минск по областям, страницы групп в них с состояниями «в поиске», «noindex · владелец», «noindex · root», «скрыта · 404»
- «Скрыть» (404, как неопубликованная; нет в поиске, sitemap и каталоге), «Принудительный noindex» (открыта по ссылке, закрыта от поиска, sitemap и каталога поверх настройки владельца), «Вернуть» / «Вернуть индексацию»; причина из шести обязательна, «Что исправить» — нет; история решений и жалоб
- Жалобы с публичной страницы: «Пожаловаться» без входа, пять причин, подробности до 500, не больше 3 в сутки с устройства, автор скрыт от организатора; в Root Admin — «Новые / Решённые», KPI, «Отклонить» или решение по странице
- Организатор: баннер с причиной и заметкой в разделе «Страница группы» вместо статуса индексации, переключатель индексации заблокирован; то же сообщение в бот («⛔ Страница группы скрыта» / «🔍 Страница закрыта от поиска»), уведомление о возврате

## Критерии приёмки

- [ ] Организатор видит причину скрытия
- [ ] Скрытая страница неотличима от неопубликованной; noindex root перекрывает `seoIndex` владельца
