Задачи для Mini App (игрок и организатор), кабинета организатора и Root Admin. Источник — макеты в корне проекта.

## Структура

- [roadmap.md](roadmap.md) — фазы, граф зависимостей по фазам, критический путь, сводка по моделям
- [links.md](links.md) — связи по общему функционалу между интерфейсами
- [01-platform/](01-platform/README.md) — платформа и бэкенд (17)
- [02-mini-app/](02-mini-app/README.md) — Mini App (25)
- [03-organizer-web/](03-organizer-web/README.md) — кабинет организатора (16)
- [04-root-admin/](04-root-admin/README.md) — Root Admin (8)

Всего 66 задач. Каждая — файл `ID-slug.md`: цель, макет, объём, состояния, API, критерии приёмки, зависимости в обе стороны и группы общего функционала.

## Сложность и модель

| Уровень | Что это | Модель |
|---|---|---|
| S | Вёрстка по готовому макету, тексты, переименования | Haiku |
| M | Компоненты с состоянием, формы, CRUD, известный API | Sonnet |
| L | Несколько экранов и сущностей, новые эндпоинты | Sonnet, ревью — Opus |
| XL | Архитектура, деньги, фоновые задачи, алгоритмы, доступ, LLM, SEO-рендер | Opus + тесты |

- Деньги и баланс (цена, сбор суммой, возвраты, списания, выплаты) — Opus и тесты на граничные случаи.
- Проверка доступа (initData, роли, приглашения) — Opus.
- Если L-задача меняет модель данных, сначала Opus пишет схему и контракт, потом Sonnet — UI.
- Haiku не трогает бизнес-логику.
