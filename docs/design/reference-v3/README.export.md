## Состав в репозитории

- `screenshots-2026-11-24/` — 218 снимков по каждому экрану и состоянию. Прежние снимки 2026-10-12 остаются в `screenshots/` как база харнесса визуальной сверки.
- `handoff/` — исходники прототипа (`*.html`, `*.jsx`, `styles.css`, `assets/`). Это эталон для вёрстки, токены — в `styles.css`. Страница открывается локально через любой статический сервер из папки `handoff/`.

Офлайн-страницы (21 файл, ≈15 МБ, шрифты и React встроены) в репозиторий не добавлены — это сборки тех же исходников; они лежат в проекте Claude Design в `export/html-parts/`.
