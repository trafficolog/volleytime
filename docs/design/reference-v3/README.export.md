# VolleyTime — экспорт для имплементации

Дата выгрузки: 3 октября 2026.

## Состав

- `html/` — 19 офлайн-страниц. Каждая страница — один файл: шрифты, логотип и скрипты встроены. Открывается двойным кликом, интернет не нужен.
- `screenshots/` — 155 снимков: постранично и по каждому экрану или состоянию.
- Исходники прототипа лежат в корне проекта (`*.html`, `*.jsx`, `styles.css`, `assets/`). Это эталон для вёрстки. Токены — в `styles.css`.
- `design_handoff_volley_time/` — пакет для разработки: README с токенами, компонентами, статусной моделью и картой экранов.
