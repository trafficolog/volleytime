между играми

Сейчас игрок открывает Mini App, чтобы записаться и проверить состав. Восемь идей, которые дают повод возвращаться: тренировки между играми, прогресс, командные ритуалы после игры и итоги сезона. Каждая — с рабочим прототипом.

Как читать
  • Проблема — какую боль игрока закрываем.
  • Механика — что делает функция и откуда берёт данные.
  • Метрика — по какому числу поймём, что гипотеза сработала.
  • Усилие — S / M / L для команды разработки.
  • Все прототипы кликаются. AI-тренер по-настоящему вызывает модель и собирает план с инструментами расписания и профиля.
  • Цифры в прототипах — примерные данные для демонстрации механики, а не результаты исследования.

Mini App после гипотез

Три способа разместить восемь функций и общий календарь. Во всех вариантах главная перестаёт быть экраном одной группы: игрок видит свои игры из всех групп сразу, а переключатель группы нужен только для её внутренних разделов. Экраны кликаются, в варианте C фаза переключается сверху.

Мой календарь

Один календарь на все группы игрока. Сейчас расписание живёт внутри каждой группы, и чтобы понять, куда идти в субботу, игрок переключает группы по очереди.
Сценарий
Игрок в трёх группах открывает вкладку «Календарь» и видит все свои записи по дням с цветом группы. «Месяц» нужен, чтобы спланировать. Фильтр по группам и переключатель «можно записаться» показывают игры, куда ещё есть места; записаться можно прямо отсюда.
Пересечения
Если записи в разных группах накладываются по времени, сверху появляется предупреждение. Игрок выбирает, какую игру оставить; место в другой уходит первому из листа ожидания.
Цвет группы
У каждой группы свой цвет: точки в месяце и метка в строке. Календарь внутри группы остаётся как есть.
Синхронизация
Подписка .ics для календаря телефона, обновляется при отмене. Сводка недели в боте по понедельникам.
Краевые случаи
Одна группа — без фильтра групп. Покинутая группа пропадает из календаря. Без сети — кэш, запись недоступна.
Метрика
Доля игроков в 2+ группах, открывающих календарь раз в неделю; число переключений групп за сессию.
