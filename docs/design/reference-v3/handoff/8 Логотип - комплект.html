Айдентика · утверждено

Галочка-
подача

Галочка подтверждения, которая заканчивается мячом: «записался — пошёл играть». Мяч увеличен, чтобы знак держался в 16 px и сильнее читался как волейбол. Ниже весь комплект: под каждым вариантом кнопки SVG и PNG.

Что в комплекте
  • 1Знак — 6 цветовых версий на прозрачном фоне
  • 2Логотип — горизонтальный и вертикальный, цвет / ч/б / инверсия
  • 3Иконки — приложение, аватар бота, фавиконка 16–64 px
  • 4Правила — охранное поле, минимальный размер, чего не делать
Один архив со всеми SVG. Те же файлы лежат в проекте в assets/logo/.
01

Знак

Основная форма. Используйте отдельно, когда рядом уже есть название: аватары, иконки, водяные знаки, мерч.

02

Логотип

Знак + название в Oswald. Горизонтальный — для шапок сайта, кабинета и документов. Вертикальный — для квадратных форматов: обложки, наклейки, экраны загрузки.

03

Иконки и фавиконка

Скругление иконки — 22% стороны (как у iOS). Фавиконка: в светлой вкладке — синий знак, в тёмной — белый с оранжевым мячом.

Реальные размеры
ФавиконкаSVG для браузеров, PNG 16/32/48 + 180 для iOS
04

Цвета

В знаке ровно два цвета. На фирменном синем знак белый, мяч остаётся оранжевым.

Синий · знак#1F2E96
Оранжевый · мяч#FF6B1F
Ink · ч/б версия#15161A
Белый · инверсия#FFFFFF
