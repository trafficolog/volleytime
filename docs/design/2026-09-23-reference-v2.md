## Актуальные токены

Финальный слой `styles.css` начинается с комментария `BENTO BOLD` и второго `:root`. Именно он перекрывает старые объявления Space Grotesk/Manrope и тёплой палитры в начале файла; это подтверждают страница Brand & System и остальные HTML-страницы. Для приложения переносится **вычисленное конечное состояние**, а не первый `:root`.

| Роль                          | Значение                                              |
| ----------------------------- | ----------------------------------------------------- |
| Заголовки и числа             | Oswald 500/600/700; заголовки верхним регистром       |
| Интерфейс и текст             | Golos Text 400/500/600/700                            |
| Фон / плитка / нажатая плитка | `#FFFFFF` / `#F4F4F6` / `#ECECF0`                     |
| Текст / вторичный текст       | `#15161A` / `#6A6B73`                                 |
| Основной / тёмный синий       | `#2437C9` / `#1A2AA3`                                 |
| Герой / оранжевый акцент      | `#1F2E96` / `#FF6B1F`                                 |
| Мягкие акценты                | `#E8EBFF` / `#FFE9DC`                                 |
| Радиусы                       | карточка 20, плитка 18, кнопка 14, чип 10, поле 12 px |
| Отступы                       | 4, 8, 12, 16, 20, 24, 32 px                           |

Карточки и поля разделяются тоном, а не постоянной обводкой; один hero-блок на экран. На Mini App: боковой отступ 16 px, 12 px между карточками, 24 px между секциями, плавающая тёмная tab bar. Контраст и focus-visible проверяются отдельно в светлой и Telegram-тёмной теме: новый архив переопределяет светлый `:root`, но **не даёт законченного Bento Bold dark-слоя**; тёмную тему нельзя механически копировать из старой палитры.
