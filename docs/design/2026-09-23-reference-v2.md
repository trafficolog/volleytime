## Актуальные токены

Очищенный `styles.css` имеет единый `:root` с токенами Bento Bold и отдельный `.vt-dark`. Ниже по файлу остаётся компонентный слой `BENTO BOLD`, но он больше не переопределяет токены. Для приложения переносится это единое состояние; старые Space Grotesk/Manrope и тёплая палитра не используются.

| Роль                          | Значение                                              |
| ----------------------------- | ----------------------------------------------------- |
| Заголовки и числа             | Oswald 500/600/700; заголовки верхним регистром       |
| Интерфейс и текст             | Golos Text 400/500/600/700                            |
| Фон / плитка / нажатая плитка | `#FFFFFF` / `#F4F4F6` / `#ECECF0`                     |
| Текст / вторичный текст       | `#15161A` / `#6A6B73`                                 |
| Основной / тёмный синий       | `#2437C9` / `#1A2AA3`                                 |
| Герой / оранжевый акцент      | `#1F2E96` / `#FF6B1F`                                 |
| Мягкие акценты                | `#E8EBFF` / `#FFE9DC`                                 |
| Радиусы                       | карточка 20, плитка 18, кнопка 14, чип 10, поле 12 px |
| Отступы                       | 4, 8, 12, 16, 20, 24, 32 px                           |

Карточки и поля разделяются тоном, а не постоянной обводкой; один hero-блок на экран. На Mini App: боковой отступ 16 px, 12 px между карточками, 24 px между секциями, плавающая тёмная tab bar. Контраст и focus-visible проверяются отдельно в светлой и Telegram-тёмной теме: очищенный архив содержит холодный Bento Bold `.vt-dark`, который должен использоваться как источник тёмных токенов.

Для мелких ссылок и текста чипов используется читаемая семантическая роль поверх брендового синего: в тёмной теме исходный `#2437C9` на тёмных поверхностях не достигает 4.5:1. Текст на зелёной кнопке также выбирается отдельно для каждой темы. Это поправки контраста в реализации, а не замена базовой палитры референса.

Авторизация: Web — выбор способа, ввод кода, ошибка кода, проверка входа, выбор организации, нет доступа, организация заблокирована. Mini App — splash/initData, ошибка initData, нет групп, доступ закрыт. Реальные API и проверки прав остаются источником состояний; фиктивные данные из JSX не переносятся.

Абонементы: переключатель организации из desktop-референса реализуется отдельной задачей 5.13.21. При выключении новые продажи и применение к новой записи блокируются сервером; купленные остатки сохраняются. Игрок с действующим остатком видит раздел без покупки, игрок без него не видит пункт меню. После включения неистёкший остаток снова применим. Настройки отдельного события для абонементов нет.
